## 2. GW 恒等式（NOTES §4）与类形式验证

### 2.1 代数恒等式推导
在链 $j$ 的 $a$-步中，输入状态为 $(x, \Theta) = (2^j u, x + D)$，其中 $u$ 为奇数，$D$ 为缺陷。
输出状态为：
$$x' = 2\Theta + 3\tau - x/2 = \frac{3}{2}x + 2D + 3\tau$$
$$\Theta' = \Theta + 3 + 3\tau$$
由此得到下一步缺陷：
$$D' = \Theta' - x' = 3 - D - x/2$$
将 $\frac{3}{2}x = x' - 2D - 3\tau$ 代入 $3D' = 9 - 3D - \frac{3}{2}x$，得到精确代数恒等式：
$$3D' = 9 - D - x' + 3\tau$$
在 `table_20000000.pkl` 中，对于所有奇 $a$-链，$\tau = 2k$（$k = \tau // 2$），因此 $3\tau = 6k$：
$$3D' = 9 + 6k - D - x'$$
当 $v_2(x') = m$ 时，$x' = 2^m \cdot \text{奇数} \equiv 2^m \pmod{2^{m+1}}$。又因 $-1/3 \equiv 1 \pmod 2$，所以在模 $2^{m+1}$ 下：
$$-x'/3 \equiv 2^m \pmod{2^{m+1}}$$
两边同乘以 $3^{-1} \pmod{2^{m+1}}$ 即得：
$$D' \equiv (9 + 6k - D)\cdot 3^{-1} + 2^m \pmod{2^{m+1}}$$
