# A four-catapult local witness using genuine canonical call data

2026-10-20. **UNREVIEWED construction with two exact replay methods.**
The initial scalar state is constructed, not claimed canonical. The
witness is safe with its stated precision and is not an EXT counterexample.

## 1. Canonical calls and explicit initial state

Calendar(256) locates actual parameter-three fires at half-times

    k_a=819270, pointer 1836654,
    k_b=229398, pointer 514272.

Put a=1836655 and b=514273. Thus X(a-1) and X(b-1) are actual
odd-a crossings with half-times k_a,k_b. Define finite positive integers

    Y0=2^a,
    Y1=2^b+2^(a+10),
    Theta0=Y1-Y0/4-21-9*k_a,
    X0=4*Theta0+12-2*Y0.

The exact initial parameter is v2(X0)=5. The choice solves the
first two five-output equations with prescribed Y0 and Y1. It does
not assert an actual canonical state with these X0 and Theta0.

## 2. Exact terminating trace

Using the canonical return table, the scalar word is

    5,1836655,5,514273,5,17,5,17,19.

Every nonterminal return is type a; X(18) is even, so the final
parameter 19 terminates. The losses are 0,1,...,8. The maximum
record is a+1=1836656, so precision a+2=1836657 strictly certifies
the entire tail. The first three catapults return to five; the
fourth goes through 17 to terminal 19. No fourth return to five
is asserted.

The construction is guided by the clock identity rather than a
blind parameter search:

    4-k_a+3*k_b=-2^17,
    4-k_b+3*6=-7*2^15.

The normalized internal clock residues modulo 4096 are 9,3,1,
matching the forced inverse-three orbit. The repeated final label
17 lies at the boundary of the train, where the internal-orbit
conclusion cannot be applied without a further catapult.

The large labels are outside [5,16381]. Thus the example contradicts
a proposed *all-scale* three-catapult cap, while respecting the
proved finite-interval and band statements.

## 3. Connection to the rational orbit, without joint reachability

For this constructed state D=Theta0-X0 satisfies

    v2(D+3)=3, ((D+3)/8)=3 mod 8.

For any H>=6, the subgroup generated by 3 modulo 2^(H-3) contains
the inverse of (D+3)/8. Hence there exists a nonnegative r such that

    c_r=-3+8/3^r = D mod 2^H.

Choose H=a+2. The rational state (X0,X0+c_r) agrees with the
constructed integer state to precision H. HP transfers the whole
finite trace because its maximum record is H-1. Therefore the
phenomenon is compatible with a high-precision representative of
the known c_r family, not only with the minimal (5,5) class.

This is an existence statement for an exponent fitting this local
state. It does not show that the orbit-generating history reaches
that exponent together with X0, or that this state lies in S(J).
The actual origin and common record budget are still essential.

## 4. Independent finite replay

    python -B work_c3_drift/verify_cross_scale_train.py

The first replay uses normalized Calendar crossing data. The second
generates a direct lambda-walk table through a-1 and applies only
the exact a-step formulas, stopping at the even return. Both give
the same word and record bound. The initial integers have about
1.84 million bits; the JSON stores their construction parameters,
bit lengths and SHA-256 fingerprints rather than enormous decimal
strings. They are regenerated exactly by the script.

This establishes a concrete cross-scale local continuation that a
global budget argument must handle. It does not enlarge K_clock,
prove global safety, or invalidate any accepted theorem.
