**Review status (2026-10-24):** reviewed via the work_gateway_trains three-way review (reviews/gateway_trains_review_record.md, group 2). Accepted as a conditional result [A-cond]+[B]; not a global ranking function.

## 1. A source/depth congruence with an explicit precision limit

At a five-input state let D=Theta-x. Write y for the next numerator,
with parameter m, and z for the next five-input's a output, with
parameter n. The intermediate m return is odd a with half-time k.
Exact elimination from the two-a formulas gives

    D=51+27k+(11/4)*y-3z.

Therefore D=51+27k mod 2^E0, E0=min(m-2,n).
If independently D=c_r=-3+8/3^r mod 2^H, put E=min(E0,H).
For E>=3, with u=(k+2)/8 (an integer by ENTRY), this implies

    3^(r+3)*u=1 mod 2^(E-3).                     (DEPTH-SOURCE)

This is a joint restriction: a source clock k and denominator depth
r cannot be selected independently. For E>=6, u must be in the
subgroup generated by 3 modulo 8, hence u=1 or 3 mod 8. Equivalently

    k=6 or 22 mod 64.

The other ENTRY classes 38 and 54 mod 64 are excluded for this
specific c_r family at that precision. This is not an exclusion for
all rational phase families or for lower-precision landings.

## 2. Application to the four-catapult local witness

For CROSS_SCALE_TRAIN, k=819270, u=102409, and
E0=min(1836655-2,514273)=514273. Matching the initial phase to c_r
to at least this precision forces

    3^r=(27*102409)^(-1) mod 2^514270.

Already its reduction modulo 2^256 fixes r modulo 2^254, whose
least nonnegative residue is

    12538662001334831796442300674852150567042723370909232292825628568973700262907.

Thus any nonnegative r meeting the full condition is at least this
value. Only the 256-bit reduction was computed; no full-size discrete
log is claimed. Existence of some full matching exponent follows from
the subgroup argument in CROSS_SCALE_TRAIN, but its causal generation
along a canonical exit has not been established.

The next pairs have E0=17 and 15, respectively. Their corresponding
normalized-clock moduli have only 14 and 12 bits. The verifier's
initial attempt to reuse 128 bits at the second source failed; the
corrected test retains that rejected assertion as a negative control.
The common exponent r+i is now checked only to each pair's actual
precision. Matching one pair at high precision does not grant that
precision to every later pair.

If this exponent were generated by r uninterrupted orbit rounds from
c_0, those rounds alone would cost 2r loss units. The local word's
high-precision phase compatibility does not supply that prefix or its
budget. Inherited phases from earlier sources need a separate ancestry
accounting; one cannot charge all inherited r to the current exit
without proving such an accounting.

## 3. A large paired gateway pays for one local denominator generation

Now take Q=3^r, r>=1, gcd(C,Q)=1. Suppose a parent chain j has
D=C/Q mod 2^j, |C|/Q<=B, j>=N_Q from ODD_DENOMINATOR, and its a
return lands at five. Its next a return has exact numerator

    y2=5*x/4+D+9k+12,
    Z=Q*(9k+12)+C.

Z is nonzero by coprimality. Let d=ceil(log2 Q). The accepted
clock estimate gives kappa<2^(j/2), B<=2^(j/2), and j>=4*(d+2).
Consequently

    |Z| <= Q*(3*kappa+B+12)
          < 2^(d+j/2+3) <=2^(3*j/4+1)<2^(j-4).

The last strict inequality uses j>=N0>20. Thus m=v2(Z)<=j-5.
Terms containing x or the phase error have valuations at least
j-2, so the actual new parameter is m. The new phase class is

    D2=(12Q+C)/(3Q)+2^m mod 2^(m+1).

Its reduced denominator is exactly 3Q, since C is not divisible
by 3. Both intermediate precision bits are justified by m<=j-5.

Let Gamma denote loss before the parent and define

    Potential=Gamma+j+2r.

At the next macro boundary it is

    Potential'=(Gamma+2)+m+2*(r+1)
              =Potential+(m-j+4) <=Potential-1.

At the intermediate five state the record is Gamma+6, also below
the parent's potential. Thus, if the potential was strictly below
a physical ceiling at the parent, both steps preserve strict safety
and pay for the added denominator generation. The potential decreases
at paired-macro boundaries, not necessarily at the second individual
step relative to the intervening five state.

Ordinary strong a/b/low-deficit-c steps with unchanged denominator
also lower the potential whenever they lower the record. This gives
a coherent budget on segments composed of these operations.

## 4. Remaining limits

The starting potential bound is a hypothesis; it has not been shown
at every entry from the original fire. Small-parent gateways, high
deficit c steps, denominator inheritance, and transitions between
separate segments are not covered. In particular the potential is
not yet a global ranking function and does not bound all reachable r.
DEPTH-SOURCE is necessary, not sufficient for a valid original history.
