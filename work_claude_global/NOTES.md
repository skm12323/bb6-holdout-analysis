## 1. exit 递推（整数形式）

把 Lemma 6.1 改写成只依赖实际 λ 小数值的整数递推。在 top-level chain 处，n=j−1：
- hpar[n]=0：返回为偶，epoch 结束；
- a 型：x' = 2Θ − x/2 + 6k_n，Θ' = Θ+3+6k_n；
- b/c 型：x' = c_X·x/2^j + λ_X，Θ' = Θ+3τ(n)+3。其中 (c_X,λ_X) 是 W 在步 τ(n) 的 chain 值。

起点是 fire：(Θ_0, x_0) = (3s_0+5, 3s_0+4)。拿真实 F 的 18,171 个 epoch 逐一对比，j 序列全部一致（`valid.py`）[B]。

## 2. 骨架算法与 r=3 反例

骨架（`skeleton.py`）的做法：
- epoch 起点 s 为奇或 s=0：走一步偶数步，指针 +2，并记下 a/b 两个交叉（头为偶）。
- s 为偶：fire，参数 J(s)。用 §1 的递推推进 chain。每次 a 型返回，在当前指针处记一个 c 型交叉，指针 +1。
- 递推只用到下标 < 200 的交叉数据，这些数据来自精确的 F（`fdata.py`）。
- 对每个头为奇的交叉 n，假想参数 J=n+1 的 fire。它的 exit 只依赖 X(n)（Lemma 6.1），可以用剩余类计算：
  - a 型：(Θ_1, x_1) ≡ (4+6k_n, 2+6k_n)，模 2^{J−1}；
  - b 型：W 在 τ(n) 的 chain 是该 epoch 起点处的 fire，c_X = 2^{n−1}+2·2^{n−1} = 3·2^{n−1}（质量恒等式），所以 x_1 = 3·2^{J−2}λ_u + λ_X ≡ λ_X (mod 2^{J−2})；
  - c 型：由 PROOF_M Lemma 3.2 情形 (c)，v2(c_X) = n−ε(n)，所以 x_1 ≡ λ_X (mod 2^{n−ε(n)})；j_1=v2(λ_X) 由 Lemma 2.1 保证（W 的 S1）。
  - 精度检查（逐步）：要求 max_t j_t + 8·(链数) + 2 < n，8 是每条链系数损失 1+ε 的上界（ε ≤ 7，PROOF_M R3）。4·10^8 范围内只有 7 个 n 不满足，全部 n ≤ 13，它们由 PROOF_M V4（J<10^6 精确计算）覆盖。

验证：
- 前 3000 个交叉的 (类型, τ, 头奇偶) 与精确 F 一致（`val_skel.py`）。
- r=3 的例子用 work_m 的 V2（λ 证书，跑到指针 5·10^7，42 秒）取 τ(50148476)=44739242 和 ε=0（a 型），再由 work_m 的 `sym_exit` 得到 ((50148477,27,6,1), 'aaba', r=3, Γ=4)（`indep_check.py` / `indep_check.txt`）。

到 4·10^8 为止的分布（`stats_4e8.txt`，下表的 r 只计头为奇的 J，即 r≥1 的那部分）：

| r | 次数 |
|---|---|
| 1 | 229,646,742 |
| 2 | 18,996,976 |
| 3 | 3 |

所有 exit 的 j 序列都严格下降。r=3 的成因：
- s=44,739,242=(2^27−2)/3，所以 j_1=v2(3s+2)=27；
- 交叉 26 是 a 型、头为奇，其 fire 参数 J(τ(26))=6，所以 j_2=6；
- hpar[5]=1，于是还有第三条链，j_3=1。

这正是 §3 公式事先预测的：r=3 第一次出现时，需要某个 a 型交叉满足 v2(3s+2) ≥ 27。

## 3. 前两步的精确公式

**第一步 [A]。** 交叉 J−1 是 a 型或 b 型时，它位于 epoch 起点 s′=τ(J−1)（P=∅，指针 ρ′），头为 (2^{ρ′}, 3s′+1)。头为奇 ⇔ s′ 为偶且 s′≥1（s′=0 的头 (1,1) 为偶）。
- a 型：返回后 x_1 = 2Θ_0 − x_0/2 + 6k = 3·2^{J−1}λ_u + 3s′+2，k=s′/2（PROOF_M P3）。所以**当 v2(3s′+2) < J−1 时** j_1=v2(3s′+2)；相等为 tie。
- b 型：exit chain 是 W 在 s′ 处的 fire 的像（PROOF_M P2，无附加条件），所以 j_1=J(s′)=v2(3s′+4)。
- s′ 为偶时 3s′+2 与 3s′+4 中恰有一个模 4 余 2。所以同一起点上 J=ρ′+1 和 J=ρ′+2 两个 exit 中，一个 j_1=1，另一个 j_1=ν(s′)=max(v2(3s′+2), v2(3s′+4))；哪一个取 1 由 s′ mod 4 决定。

**a→a 第二步 [A]。** 设交叉 J−1 是 a 型、头为奇，K=k_{J−1}，m=j_1−1，k'=k_m，且交叉 m 也是 a 型、头为奇。由 Θ_1=Θ_0+3+6K=2^Jλ_u+4+6K 代入得
x_2 = 5·2^{J−2}λ_u + 7+9K+6k'，而 7+9K+6k' = 3(3K+1) + 2(2+3k')。
- 3K+1 = 2^{m}·奇数；
- 交叉 m 是 a 型，位于 epoch 起点 s''=τ(m)=2k'，s'' 为偶，所以 2(2+3k')=3s''+4=2^{J''}·奇数，J''=J(s'')。

因此**当 J''≠m 且 min(J'',m) < J−2 时** j_2=min(J'', m)。
J'' ≤ log2(3τ(m)+4)；用 m 处的 (C1) τ(m) ≤ m² 得：m ≥ 8 时 J'' ≤ 7 < m（3·64+4=196<2^8；m=7 时此界失效，阈值 8 是紧的），tie 不可能且 j_2 < j_1。m < 8 的情形是对 τ(m) 的有限检查。
首步为 b 型时此公式不适用（数值盲审员：J<20000 中 38/317 例不符），b 型首步之后的第二步需要另给 b 返回的 Θ/x 公式。

`check_aa.py` 对 J<20000 验证了第一步 6053+6053 次、a→a 第二步 316 次，全部吻合，tie 出现 0 次 [B]。

## 4. 建议路线：严格下降引理 DL

**DL.** 在每个 ρ > N_B 的 epoch 中，exit 参数严格下降：J = j_0 > j_1 > … > j_r。

**DL ⇒ (EL)，在 Theorem M 的归纳之内。** DL 给出每个 epoch r ≤ J−1。由 ρ 处的 (C1)（s_0=τ(ρ) ≤ ρ²）得 2^J ≤ 3s_0+4 ≤ 3ρ²+4，所以 r ≤ 2log2ρ+1 ≤ ⌊log2ρ⌋²（ρ>10^8）。ρ>10^8 时 (C1) 本身来自 Theorem M 的归纳（归纳到前面的 epoch），所以正确的说法是：把 DL 代入 Theorem M 的归纳，每一步都得到 (EL)，从而 F 处处有定义、universal walk 不停机。DL 按 epoch 陈述、只涉及实际的 j_t，不需要 tie-free 假设。

已有的部分（各自的前提）：
- (i) t=0 的一步：a 型首步用 P3，需要 J−1 处的 (C1) 且 J ≥ 10；J<10 可在任意 ρ 出现，是对 τ 的有限检查。b/c 型首步见 (ii)。
- (ii) 任意 t（含 t=0 的 c 型首步）的 b/c 返回：exit chain 是 W 在 τ(n) 的 chain 的像（PROOF_M 引理 2.1、P2），所以 j_{t+1} 等于 W 在那里的 j ≤ log2(6τ(j_t−1)+5)。由 (C1) 得 j_t ≥ 9 时 < j_t（j_t=8 时仅用 n² 不够）；更小的 j_t 用 τ(n) ≤ n（n ≤ 10^8 已证，见 work_m/PROOF_M.md §4 V2 结果：s/i ≤ 0.8928，B 类）。
- (iii) t=1 的 a→a：§3 的公式，只覆盖"交叉 J−1 与交叉 m 都是 a 型且头为奇"并满足 §3 所列条件的情形。

缺口（DL 的全部未证内容）：t ≥ 1 时的 a 型返回，分两类：
- (G1) 前一步也是 a 返回（t≥2 的 a→a）。由 POS，若前一步也是 a，则 j_{t+1}=min(j_t−1, v2(6(k+l+1)))，除非发生碰撞 v2(k+l+1)=j_t−2。
- 碰撞要求 2^{j_t−2} ≤ k+l+1 ≲ (j_{t−1}+j_t)/2，也就是 j_t ≲ log2 j_{t−1}+1。所以碰撞只能发生在已经对数下降之后。
- 碰撞之后 j_{t+1} 取决于 x_{t−1}, x_t 的高位，可能回升（"reset"）。
- 合成态 17,5,17,17,1（PROOF_CORE §6）说明，单靠局部规则无法排除回升。
- (G2) 前一步是 b/c 返回（包括 b 型首步之后的 a 返回）。POS 不适用，需要把 b/c 的仿射更新 x'=(c_X/2^j)x+λ_X 与 a 更新联立，目前没有任何分析。

**新要素：真实 exit 的状态是"规范"的。** 首步为 a 型时这一点已证明：K ≡ (2^m−1)/3 (mod 2^{m+1})，m=j_1−1，所以 Θ_1=2^Jλ_u+4+6K 模 2^{m+1} 由 j_1 决定（x_1 模 2^{j_1−1} 只是 0，信息都在 Θ_1 里）。首步为 b 型时，s′=τ(J−1) 满足 s′ ≡ −4/3 (mod 2^{j_1})，但要由此推出 (Θ_1, x_1)，还缺 b 返回的 Θ/x 公式，**尚未证明**。

因此（a 型已证，b 型待补）整个尾部 Tail(t, j_1) 只要精度够用，就是 (t, j_1) 的函数，与 J 无关。合成反例用的是非规范的剩余，不在这个集合里。
- `markov.py`：j_1 ≤ 660，每种首类型取 3 个随机规范起点。尾长 ≤ 3，严格下降无一例外 [B]。
- 小 j 处的转移并不只由 (前一类型, j) 决定，例如 (a,5)→{1,2,3}。所以证明需要保留规范剩余本身，不能只看 j 图。这与 PROOF_CORE §5 的警告一致。

**下一步（按优先级）：**
1. 把"规范状态"写成精确引理。对 (首步类型, j_1)，给出 (Θ_t, x_t) 在模 2^{j_1−1−G_t} 下的闭式；G_t 是 compression 笔记中的系数损失。
2. 在规范状态上证明碰撞后的回升不会超过 j_t。碰撞条件只涉及小下标 n<j_1 的交叉数据，以及 j_1 的规范剩余。目标形式：对所有 j_1，"tail 碰撞 ⇒ 结果 < j_t"。可行的手段：对 j_1 归纳，加上 §3 那样的显式公式（J'' ≤ log 型界）。
3. 如果第 2 步做不到，退一步：只要能证明"Tail(t,j_1) 的长度 ≤ C·j_1"，同样推出 (EL)，因为 r ≤ 1+C·log2(3J+4)。
4. endgame（有限 v 的真实机器）仍是独立缺口，本路线不涉及。
