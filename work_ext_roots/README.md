# 直接研究 EXT 的真实入口

2026-10-18，新结果未独立审查，EXT 仍开放。

- b 型符号退出入口满足 `Theta=x`，并非实 fire 的 `Theta=x+1`。
- c 型入口满足 `Theta-x=-lambda_Y`，必须保留实际来源尾块与时钟的关联。
- 新的一变量精确搜索覆盖混合 b/c 走廊。所选 2621 个生产性来源中，
  零相位差起点最多经过两个生产性块，未出现逃逸；这是有限结果。
- 对一个固定的首个 tie 候选词，令 M 为累计块损失加末参数：
  b 型外层指标必满足 `J<=M+2`，c 型最小反例必满足 `J<=2M`。
  还必须通过严格新纪录条件及实际来源同余检查。

完整推导见 [PROOF_EXT_ROOTS.md](PROOF_EXT_ROOTS.md)。候选词本身的长度
和参数仍无全局上界，所以有限来源检查尚不能闭合 EXT。

继续推进：[固定前缀的完整末步过滤](PROOF_LAST_TIE.md) 给出未决末参数
的显式上界，同时枚举全部外层来源。504 个有限前缀的 8064 个末参数
诊断全部排除实际来源（来源只在已认证的 J<128 诊断范围内被检查；J>=128 时该字母表下没有可达来源）；另有一个**非规范来源**的精确 tie 正对照被保留，
说明实际来源关联不可省略。前缀族仍未得到全局控制。本目录已通过三方审查（reviews/ext_roots_review_record.md）。

新增 [低亏损 c 来源归约](PROOF_LOW_DEFICIT.md)：提出两条全尺度证明，
在最小 EXT 反例归纳中排除全部 `epsilon=3` 的 c 来源，并通过相位二
吸收排除 `epsilon=5` 且历史为 BA 的来源。`epsilon=5` 的 AA 历史、
更高亏损及 b 型来源仍开放。80 个规范来源例子与附加代数检查通过；
**这两条证明尚未独立审查，不视为已接受结论**。

进一步：[A 起始来源的谱系归约](PROOF_A_SOURCE_DESCENT.md) 为 AA 找到了
实际更早的 b 来源，提出排除全部以 a 返回起始的来源 epoch 的证明，
不再限制其后续亏损或混合返回次数。若审查通过，c 型最小反例只需考虑
`epsilon>=7` 且来源 epoch 首次返回为 b/c 的情形；b 型入口仍开放。
该任意历史论证依赖已接受的 AB/HP 精度结论，尚待独立审查。

最新：[亏损七的 CA 归约与两类相关入口](PROOF_DEFICIT_SEVEN.md) 进一步
提出 CA 的全尺度归约。亏损七只剩 BAA/BBA 两种来源历史，分别化为
`(x,Theta)=(6k+6,6k+5)` 与 `(6k-2,6k+1)`，其中 k 必须是实际调用半时钟。
两类的全尺度终止/余量界仍未证明。有限及深层日历检查通过，并发现
PLUS 的“立即结束”现象不能从小范围扫描推广到全局。
