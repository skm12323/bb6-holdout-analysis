# 核心重复访问的限制

推导见 `PROOF_REPEATS.md`，未启动独立审查。

- 任意两个连续同参数的混合返回块，下一参数精确等于
  `1+v2(T_q)`。在较早 C1、C2 条件及小表基础上，它严格小于 q，且安全。
- q<=4095 的所有 1304 个可返回参数中，这个输出均为 1、2 或 4，
  因而直接结束。
- 对参数 5..255，精确同余格求解排除了全部 6162 个不同参数有序对
  的五项交替模式 `q,r,q,r,q`。没有以有限奇数基数采样代替证明。

仍缺三个以上参数形成的长循环或不周期访问的控制，也没有证明核心
访问次数上界。JSON 保存可重现结果，脚本不宣称测试词实际可达。
