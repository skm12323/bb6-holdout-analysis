# 固定核心内任意访问序列的闭合证书

证明见 `PROOF_WORDS.md`，未启动独立审查。

- 参数 <=1023 的全部生产性返回块词被精确同余格搜索覆盖。
  长度 2..7 的可行词数为 105625、25438、17378、6271、504、0。
- 不仅短周期，任意七项连续核心词都被排除。
- 逃出该范围的分支只出现在已匹配长度 2、3、4 的节点之后。
  已经连续达到五个核心入口后，后续逃逸也被排除。
- 第五个入口的系数赋值 >=1034 时，剩余尾段最多 2730 个 F 步结束，
  系数损失至多 10。此前所需的有效前缀及 replay 条件仍适用。

没有证明核心与大参数之间反复逃逸/重入的次数有界，也没有覆盖任意
增长的核心范围。脚本的可行词只是必要算术条件，不表示实际可达。
