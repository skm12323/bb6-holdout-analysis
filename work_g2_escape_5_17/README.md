# 首个关联逃逸入口 (5,17)

证明见 `PROOF_ESCAPE.md`；本轮没有启动独立审查。

保留原参数 17 的奇数基数 v，逃逸状态精确满足
`Theta=X/2+2^15 v+21`。其奇 a-return 除
`k=32761 mod 65536` 外，返回后的尾段最多 13 步安全结束，逃逸高度无上界。

剩余 a 类若回到参数 17，会精确返回同一状态族。这个子分支满足
`delta_new=delta/4+3(k+7)`，可控制负值阶段和合法尺度界内的算术高度，
但尚不能控制正值区域的重复次数或保证每次回升安全。

16 个符号柱集证书和 20 个完整整数对映射检查通过。仍缺其他共振输出、
b/c 来源输出 1 的碰撞以及重复重入的统一处理，未证明全局闭合。
