# 保留两个调用时间后闭合高参数 a 分支

证明见 `PROOF_TWO_PHASE.md`，未启动独立审查。

- R21 逃逸后的 E 状态有两个未决 a 时间类；其余类在返回后最多 16 步结束。
- 不丢弃前一调用时间，可把两个剩余类分别转回 R21 或相位 -2 的 D 族。
- R、E、D 的相关小参数范围分别有 1007、1006、1008 个完整仿射闭合证书。
- 两个入口均 >=1024 且 <=2^500、两处都是奇 a-return、第二入口已经安全，
  并有较早 C1 时，后续尾段闭合。该结论没有自行证明第一处高位共振安全。

高参数 b/c 分支、共振入口的安全条件，以及不同模式之间反复切换仍未解决。
