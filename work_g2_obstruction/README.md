# G2 续推：有限 fire 谱、严格下降障碍与安全退出族

**已于 2026-10-14 通过三方审查（攻击员：可修补，已修补；复算员 ×2：all correct）。审查记录见 `reviews/g2_obstruction_review_record.md`。**

## 主要发现

利用已接受的 `work_tie` 有限定理（每个相关行程至多 6 条退出链），先得到相邻 fire
的步数上界，再用整数“不能越过目标”的论证，证明有限范围内足够多的 fire 参数必然出现。
由此构造出真实轨道中的候选存在性见证：

```
p3 → p2 → 244875 → 17 → 5 → 6 → 1 → 结束
```

前三个箭头为 b 返回，之后是已接受的救援尾段。p2、p3 是由真实 fire 的指针定义的整数，
没有直接模拟计算出来，但证明给出的上界使整个见证处于已有有限证书范围内。

**若这份推导通过复核，全局 DL 严格下降目标即被反驳；已有 r≤6 的有限界也达到取等。**
这不是停机反例：整个行程安全结束。`5→6` 属于 G1，不能称为完整 G2 的无条件反例。

同一见证在参数 6 处还有 b 返回，其偏移为 `44 mod 64`（有符号值 −20）。
因此，G2 研究中提出的“每个 b/c 复制的偏移都在 {0,±1,−2}”这一未证目标也不封闭。
已证明的短前缀结果不受影响；仍可只约束真正遇到 a 返回的非平凡复制。

## G2 的正向推进

对末端复制到已知参数-5 fire 的纯 b 链，证明了深度 m=1..123 的一个规范族均安全退出：

```
最后一个父参数 65 → 5 → q，q=1+v2(124-m)≤7
```

尾段最多 61 步结束，其中 m=12,28,44,60,76,92,108 不满足单步严格下降，仍然安全。
这是一条对兼容入口统一成立的局部证明；并未证明所有这些深度在真实轨道上都出现。
若有足够长的实际 fire 祖先链，m=12 会给出 G2 的 `5→5` 非下降；这个更长祖先链
目前只在附加全局 fire-gap 条件下得到，不能与上面的有限 G1 见证混淆。
