# 特定重入模式的重复次数界

证明见 `PROOF_BUDGET.md`，未启动独立审查。

对安全的连续 `R21(Q) ->17 ->R21(Q_new)` 段，保留旧变量后得到

    d_new=(d+3t)/4,
    N_new-N=(9t-d)/4,
    Q=17+v2(N)。

较早 C1 迫使此模式的 Q>=257。若有限前缀的参数上界 g<=2^127，
进入收缩公式给出的高度窗口后，不能再连续完成两轮。因此总连续
段数至多 `ceil(log_4(max(1,|delta0|/M_g)))+1`，并有显式耗时与损失界。

这是特定模式的次数界，不是 epoch 终止定理。离开模式后的高参数
输出、其他返回类型、间隔后重入以及更大尺度仍需处理。
