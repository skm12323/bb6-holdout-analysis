# G2 共振与祖先追溯

本轮基于已接受的 `work_g2_obstruction` 审查结果继续推进，没有修改旧证明。
新证明尚未经独立审查，详见 `PROOF_RESONANCE.md`。

1. 固定末端来源为已知的参数 5 fire（rho=63）时，将原先 m=1..123 的
   安全尾段推广到所有正整数深度，唯一暂不统一闭合的类为
   `m ≡ 124+2^61 (mod 2^62)`。其余情况从参数 65 起最多 112 个 F 步结束。
   这是 62 个双变量仿射族的完整符号证书，不是深度采样外推。
2. 对任意真实的初始纯 b 祖先链，在较早交叉处的 C1 假设下，保留至多
   O(log m) 层祖先即可消除第一次 a 回升的估值碰撞，证明其安全。
3. 对一般初始 b/c 前缀，在较早交叉处的 C1、C2 假设下，第一次奇 a
   回升安全，且参数小于 `3 log2 J+2`（J 为原始 fire 参数；解析证明要求 J>=1024，更小的 J 由 J<4096 证书覆盖）。

尚缺：异常类第一次回升之后的统一尾段终止，以及足以闭合全局归纳的
总长度、系数损失界。没有宣称证明全局不停机或扩大无条件有限范围。

验证脚本、JSON 证书和运行摘要均保存在本目录。代数测试用的合成祖先
不表示它们在实际轨道上出现；一般深度族也不附带可达性断言。
