# 深度 9 mod 16 的返回块

本轮没有启动审查。推导见 `PROOF_BLOCK.md`。

新结果：

- 把未决纯 b 分支写成精确的两变量返回块，并保留来源 (A,B,m)。
- 证明安全回升后进入同一扩大状态族 `Theta=x/2+8v+6`；这一事实本身
  不意味着该分支安全，也不意味着会无限重复。
- 在较早 C1 条件下，单块耗时为 O(q²)，系数损失为 O(log q)。
- 非终止的此类块必须有至少 9 次 b 复制，因而 q 至少为 16640；
  低于该阈值且纯 b 前缀到达 5 的相关状态可直接闭合。
- 形式代数例子表明，丢弃真实来源约束后，参数和旧奇数基数都可以
  增大。例子不是实际轨道，也不满足全部 C1，不能用来否定真实归纳。

360 个精确块恒等式与 3 个形式回升构造检查通过。仍缺来源约束下的
返回块次数界或递降秩，未宣称全局证明完成。
