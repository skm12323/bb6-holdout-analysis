# b/c 复制分支与深度同余判据

未启动审查。新推导见 `PROOF_SHIFT44.md`。

- 对高参数 reset 状态，b/c 复制相对较早来源的相位差恰有二进赋值 2。
  来源前缀若直接结束，或其第一次奇 a 返回输出不是 3，整个外层尾段
  可以证明结束；低系数精度情形也可直接用已完成尾段的跟随定理闭合。
- 若初始纯 b 前缀在 m 次复制后到达参数 5，则除 m=9 mod 16 外，
  下一参数为 `1+v2(9-m)<=4`，余下最多 6 步结束。
- 特别地，直接复制任意参数 5 fire 都产生 `q,5,4`，无需限定来源时间。
