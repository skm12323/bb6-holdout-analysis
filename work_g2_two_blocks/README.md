# 连续两个未决返回块

新推导见 `PROOF_TWO.md`，未启动独立审查。

核心进展是消去第一个块之前的未知奇数基数，得到正项恒等式：

    X2=(alpha/2)X0+(1-beta/2)X1+C。

在真实来源满足较早 C1 时，`0<C<10Q²+18`，其中 Q 是两个入口参数
的最大值。若两个入口都不小于 `2 ceil(log2(10Q²+18))`，第二次回升
必安全且落到 `ceil(log2(10Q²+18))` 以下。

这排除了连续三个都处于该对数核心之外的返回块入口，并给出两块的
精确耗时及系数损失。它没有证明核心访问次数有界，也不是全局递降秩。

96 个精确恒等式检查和 4037 个界常数检查通过。合成检查不表示实际
轨道存在两个这样的未决块；实际来源约束用于正文中的条件性推导。
