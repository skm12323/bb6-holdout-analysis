# 不依赖退出长度的全局时钟界

2026-10-16；新推导，尚未独立审查。详见 `PROOF_CLOCK.md`。

对从初态出发的最大有效 F 前缀（包括可能的首个失败状态），尝试独立
证明 C1 及更强的 `s<=i P(i)=O(i log² i)`。关键是相邻原始位置之间
只需等待一段严格下降的 b/c 链，不必等待整个 epoch 结束。

据此得到每个 epoch 的长安全前缀，使用的仅是 `epsilon(n)<=n`，
不需要 C2。进一步把全局不停机归约为更弱的 SQRT-EXIT 条件：
每个高指针 epoch 在 `floor(sqrt(rho))+1` 个退出链之前结束。

SQRT-EXIT 仍未证明，不能把条件性全局定理视为全局不停机证明。
脚本验证了 8191 个精确相邻交叉时间差和 135 个界常数实例。
