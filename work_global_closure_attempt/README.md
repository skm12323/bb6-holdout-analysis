# 全局闭合尝试：更小的参数范围与长局部路径

2026-10-18。**未闭合全局证明；作为条件性/局部结果已通过三方审查**（reviews/global_clock_horizon_closure_review_record.md）。

- 推导：最小反例所需的安全前缀，链参数可界为
  `ceil(log2 J)+2ceil(log2 ceil(log2 J))+7`。
- 新的充分条件：若所有参数不超过 Q 的可行生产性混合返回词，
  长度均不超过 `2^ceil(Q/2)`，则结合已有归纳预算可推出全局 EXT。
  **这个全尺度长度界尚未证明。**
- 精确搜索发现并构造了 9 个连续 a 返回输入的正值、安全局部路径；
  其中后 8 个入口为 a 输出。其 true-fire 投影为空，不能当成实际
  初始轨道上的反例，也不能用局部路径声称出现停机。

详见 [证明与剩余缺口](PROOF_CLOSURE_TARGET.md)。复现脚本为
`probe_words.py` 和 `verify_cap.py`，均仅依赖标准库与仓库现有代码。

后续见 [起点相位过滤与扩大搜索](PROOF_ORIGIN_FILTER.md)：64 个实际
来源参数中，任意局部起点允许长度 11 的纯 a 词，fire 起点最多长度 2。

为 `2^122438-3244676`。新十一项词已构造安全正值局部 lift，但仍无
canonical ancestry。全局证明和全尺度 W 界均未闭合。
