# 全局路线续探：保留关联的来源压缩

本轮材料位于新目录 `work_global_compression`，未修改之前的研究结果。
**仍未得到全局不停机证明；以下新推导待独立审查。**

## 新进展

证明了一个“消去来源起始时刻”的公式，可以把巨大时刻替换为由较小交叉数据决定的奇分母有理数。
更重要的是，给出了需要一起保存的关联：

```
A·Theta − 2^G·x ≡ C  (mod 2^L)，A 为奇数
```

这条关联在 a、b/c 转移下都有精确更新式，**模数精度不因这些更新而损失**，也不要求参数逐步下降。
复制时的精度预算与来源行程的起始指针有关；因此可以把它与上一轮“完整尾段复制”引理配合使用。

对“来源从起点经过 b/c 前缀，再遇到第一个 a 返回”的情形，还给出了条件复杂度界：
在按早期行程归纳的假设下，压缩所增加的算术高度为 `O((log J)^3)`，
其中 J 是较小的来源参数。该界不能直接套用到含任意多次 a 返回的来源前缀。

## 排除了一条错误捷径

即使固定有理相位为 `6 − 8/3^1022`（实数值接近 6），仍能构造出
满足质量恒等式、正性和局部安全余量的状态，使参数依次为：

```
17 → 5 → q，q 可取任意整数 q≥24
```

这些是构造状态，**未证明在真实轨道上可达**，也不是对机器不停机的反例。
它们说明：只保留压缩后的 theta，或只控制其数值大小，仍不足以建立全局下降；
必须保留上面的时间量—链值关联及其来源信息。

## 验证与剩余问题

- 枚举参数 `J=2..4095`，得到 1,304 个首个 a 返回的系数记录。
- 80 组完整大整数来源运行、720 次压缩同余、84 次关联更新、1,476 次复制同余均通过。
- 无界跳升构造在 107 个 q 值上完整复算通过，包括 q=4096。

下一项真正的证明义务是：给任意来源前缀建立统一的关联复杂度与精度余量界，
并控制同阶估值碰撞的累计次数。这项归纳尚未闭合。
原图灵机的实际边界结尾阶段也仍需单独完成证明。
