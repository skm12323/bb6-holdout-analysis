# 继续推进：退出长度问题的低参数核心改写

**本轮得到新的符号改写（三方审查未发现数学错误），尚未得到全局不停机证明。**

注意：这不是难度上的降低。CORE2 与原退出长度引理在预算相差约 3 倍的意义下等价：
若每个行程至多 b−1 条退出链，则 CORE2 成立；反之 CORE2 给出至多 3b+1 条退出链。
改变的是目标的结构形式，而非其强度。

连续两次 a 返回满足精确恒等式：

```
x(t+2) = (x(t)+x(t+1))/2 + 6(k+l+1)
```

由此证明：若参数上界为 g，且所用早期交叉满足已有时间界，则参数大于
`K(g)=ceil(log2(6g²+6))` 的链**最多连续出现两条**，无需假设每步下降。
因此，若低参数区间的访问次数为 m，整段链数至多 `3m+2`；
相邻两次低参数访问之间最多有三次转移，可表示成短的精确仿射映射。

进一步给出了可审核的条件全局定理：
若每个大行程中由自举论证保证的前缀都达不到 `b+1` 次核心访问（b=⌊g²⌋；J≤K 时初始 fire 也计一次），则已有基例可通过放宽常数后的
定理 M 归纳推出 **F 的全局不停机**。这个访问次数界（CORE2）仍未证明。
原图灵机的实际边界结尾阶段仍有独立缺口。

这条路线把下一步表述为很小参数区间内的重复访问（与原问题等价，并未更容易），并保留上一轮的联合同余与来源信息。
不能只凭参数种类少、或者仿射映射的某个系数小于 1，就断言会终止。

验证：2,479 个真实小范围行程、110 个构造行程全部通过；
核对了 148 次两步恒等式与 298 个低参数返回映射。
但真实行程中（含审查者的 302,878 个）只有约 3–30 条链超过阈值且互不相邻，
两连高参数检查在真实数据上是空检查；该上界及多数共振检查来自 110 个构造行程。
真实两次 a 返回共 28 例，奇偶相同，下一 j=1；观测最大 m=3，最大 m/g²=0.0156（C 类弱证据）。
构造序列 `17→5→17→17→1`（从构造的非空列表状态出发，非 level fire）达到“两条连续高参数链”的上界，
但不说明 `3m+2` 是紧的（N=5，而 m=2 时界为 8）。
之前的大跳升样例也继续运行到了结束，包括 `17→5→4096→2`。
