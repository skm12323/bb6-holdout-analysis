## 1. 原机器与 F 的关系

已接受的事实：
- （R1、R4）机器停机 ⇔ 顶层映射在某个奇数 A 的步上有 A+2b+3 为 2 的幂。单元素列表 (3n+3) 永不停机。n 为偶数时，下一状态是 excursion
  E(w,v) = (U+1; U, 2U, …, 2^{v−2}U, 2^{v−1}U − 1)，其中 U=3w，n+2 = 2^v w，w 为奇数。
- （G6 §5 D5）E(w,v) 与 universal walk F（原始项 E_a = 2^a·U 无限延伸）**逐步一致**，直到第一次读取下标 v−1 的那一步为止（队列确定性）。这一步之前的状态就是 F 的交叉状态 X(v−1)。
- 在 pair 表示 (c,λ) ↦ cU+λ 下，只要每条链满足 S1（v₂(λ_x) < v₂(c_x)）与 S2（c_A 为偶），实际值的 2-adic 赋值就与 U 无关，u = (c_x/2^j)U + λ_x/2^j ≥ 2U+1 > 1，不可能停机（PROOF_M、G6 §5.2）。

**endgame** 指从 X(v−1) 开始，到 excursion 回到单元素列表（或者永不回到）为止的这一段。与 F 的区别只有两点（work_r10/agentC10_report.md §1）：
1. 下标 v−1 处的项是缺陷对 (2^{v−1}, −1)，λ 为负；
2. 此后没有原始项，队列只剩一个元素时，第二个读入项按零对 (0,0) 处理。

## 2. 不停机实际需要什么

对每个出现的 v（即每个满足 n+2 = 2^v w 的单元素时刻）：

- **(F 部分)** F 在 X(v−1) 之前的每条链都满足 S1。只要 F 处处有定义，这一条就对所有 v 成立；而 PROOF_CLOCK（已接受）证明了 SQRT-EXIT ⇒ F 处处有定义。
- **(EG-SAFE)** endgame 中的每条链都满足 S1 与 S2（S2 由 E5 的缺损界 d < n 给出；PROOF_CLOCK 的“S2 保持”只覆盖 F）。由此可知 endgame 中没有链停机（E3）。

**endgame 不需要终止。** 如果某个 excursion 的 endgame 永不回到单元素列表、但也永不停机，机器同样不停机。终止只是让单元素时刻的归纳能继续下去；不停机的证明只需要 EG-SAFE。不过，链若无限多，下面的边际会被耗尽，所以安全性在实际上仍要求链数受控。

## 3. 已有的 endgame 引理（来源与审查状态）

**更新：** 修订后的 E1–E5 已经过三方审查，见 `LEMMAS_E.md`，应引用该文件。本节以下保留原始陈述，仅供对照。

work_r10/agentC10_report.md §1 声称以下引理为 [Class-A]：

- **E1（边界模拟）**：只要各链满足 S1、S2，pair 演化就精确对应真实顶层轨道，且与 U 无关。
- **E2（负号不传播）**：除尚未读取的缺陷项外，所有 λ ≥ 0；每条链 λ_x ≥ 2；每个 push 的 λ_u ≥ 1 且为奇数。
- **E3（安全）**：在 S1 下 u ≥ 2U+1，endgame 链不可能停机。
- **E4（质量）**：缺陷项读入后 c_A + Σc = 2^v，λ_A + Σλ = 3s；终点恰为 (2^v, 3ℓ(v))；每条 endgame 链满足 j ≤ log₂(9s+6)。
- **E5（缺损排空）**：只要
  (v−1) − D_cross > maxj + Σ_{endgame 链} j + 1，
  每条 endgame 链的 S1 就自动成立。这里 D_cross 是交叉缺损 ε(v−1)，maxj 和 Σj 取遍 endgame 的各条链。

审查状态（work_r10/ASSEMBLY.md、review_audC10.md）：
- 五方审查推翻了"endgame 对所有 v 闭合、不留额外残差"这一说法：固定 2^18 柱面方法在 v=97957 起失效；e(v) ≤ 16 不成立（e(391796)=17，到 4·10^6 时最大为 20）；类集合不封闭。
- 审查员独立复现了 E1 型归纳，"E5 边际 + 稳健性"这条只谈安全的路线**没有被数据推翻**，但其中只做了抽样（B 类）。
- **E1–E5 本身没有经过逐条的三方审查**，使用前必须单独审查。

已有的有限证据：对 v ≤ 65536 穷举、v ≤ 4·10^6 复算（与 U 无关），endgame 均不停机且回到单元素列表；实测 endgame 步数 e(v) ≤ maxj+1，到 4·10^6 无反例。

## 4. 与 PROOF_CLOCK 结合后的归约

设 SQRT-EXIT 成立（于是 F 处处有定义，且 PROOF_CLOCK §6 给出新的 c 型交叉满足 ε < ρ/4，a、b 型的 ε ∈ {0,1}），并设 E4、E5 成立。则当 v−1 > N_B 时：

- D_cross = ε(v−1) < (v−1)/4；
- 交叉时刻 s_cross = τ(v−1) ≤ (v−1)·P(v−1)（PROOF_CLOCK 的 CLOCK，无条件）。所以 endgame 中 s ≤ s_cross + (endgame 步数)，进而 j ≤ log₂(6s+5) = log₂ v + O(log log v)（LEMMAS_E 的 E4），只要 endgame 步数不超过 v 的多项式；
- 用 E5 的前缀形式（LEMMAS_E §5）：只要 Σ_{i≤k} j_i < n − D_cross，第 k 条链就安全。因此只需
  (endgame 链数)·(log₂ v + C) < 3(v−1)/4，
  其中 C 是可以显式算出的常数（不再需要原条件中单独的 maxj 与 +1）。
- 注意 ε < ρ/4 是 PROOF_CLOCK §6 对新 c 型交叉给出的界，这里取交叉 X(v−1)（指针 ρ ≤ v−1）。按 PROOF_M 引理 3.3，X(v−1) 要么是新的 c 型交叉（ε < ρ/4），要么 ε ∈ {0,1}（包括 a、b 型及非新的交叉）。
- s 还随偶数步增长。步数可以由链数与 Σj 控制：每个偶数步至少移除一个队列项，每条链至多净增加 j−1 个（当 c 为零对时只移除一个项）；正式版本须写出这一点。

于是 endgame 义务归约为一个**链数界**：

> **(EG-LEN)** 存在显式常数 C 与 V₀，使得对每个 v > V₀，endgame 的任何有效前缀上 Σ j < 3(v−1)/4（例如：链数不超过 ⌊(3(v−1)/4)/(log₂ v + C)⌋）。

它和 SQRT-EXIT 同属一类问题（顶层链数不能过多），但数值上更弱：允许约 v/log v 条链，而 SQRT-EXIT 只允许约 √ρ 条。**更正：** work_r10 中的 e(v) = ℓ − s_cross 是 endgame 的**步数**而不是链数；实测 e(v) ≤ 20（v ≤ 4·10^6），链数只会更少。

这里的推导需要把"endgame 步数为 v 的多项式"同时作为前提或结论处理，正式证明时应仿照 PROOF_CLOCK §5：先在固定预算内对每条链的候选参数作界，再证明在预算内要么终止，要么所有链都安全。这一步尚未写出。

**统一的目标。** 若能证明"每个 F epoch 与每个 endgame 的顶层链数都不超过 √(指针)"（SQRT-EXIT 加上它在 endgame 上的版本），则在 E1–E5 被审查接受的前提下，#1 不停机。
