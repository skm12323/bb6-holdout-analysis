# 任意 a/b/c 路径的根精度预算

2026-10-16，新推导，尚未独立审查。

`PROOF_MIXED_PRECISION.md` 将此前只适用于连续参数-5 救援段的根变量
方法推广到任意混合返回。高位项的赋值始终精确等于 P-G，低位截距
保持正且受累计时间控制。C1 及首个调用处 C2 条件下，前
`1+floor(P/(16 ceil(log2(12P²))))` 个返回若出现，均安全，参数进入
固定的 O(log P) 核心。

对真正 fire，过程可化为固定初值的标量截距递推。50176 个有限范围
仿射族全部结束，但任意 P 的停止性质仍未证明；不能把安全预算当作
退出次数界。主目标及精确的剩余条件保留在证明第 4 节。
