# 保留根变量的多层共振梯级

2026-10-16，新推导，尚未独立审查。见 `PROOF_LADDER.md`。

连续通过参数 5 的两次 a-return 可统一规范为
`delta_n=6-8/3^n`；精确说明了该相位规范何时下降、何时会丢失高位。

进一步保留最初 U,z 和全部调用时间，证明对 P>=64、较早 C1 成立的
兼容初态，前 floor(P/4) 个此类段（若出现）均安全。P>=1024 时，
所有回升参数 <2 log2 P+3，累计时间 <=5P²/4，系数损失至多 P/2。

这不是退出次数界：段可能提前离开此模式，而固定核心证书尚未推广到
任意 P。也未证明能在根精度预算耗尽前结束。
