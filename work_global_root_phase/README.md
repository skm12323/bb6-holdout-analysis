# 从真实 fire 出发的系数权重与首层共振

2026-10-16，新推导，尚未独立审查。见 `PROOF_ROOT_PHASE.md`。

- 在 a-output 交叉处，精确有 `epsilon=W+1`，其中 W 是累计系数损失
  加 a-return 次数。c-copy 的权重包含来源历史，不能独立重置。
- 权重 <=8 的根相位语法可完整列出。真实 `17,5,17` 中间交叉必须
  `epsilon>=11`；旧局部构造指定的 epsilon=3 系数配置不可能实际可达。
- 首个可能的 NT 失效出现在 BBB A 后的 `(5,5)`。其下一回升满足
  `q=v2(9k+10)<p-2`，安全且保留 `3Theta-2x=10 mod 2^(p-1)`。

这补充了真实可达性约束并统一处理首个共振层，但仍未证明任意权重的
退出次数界，不能宣称全局缺口已经补完。
