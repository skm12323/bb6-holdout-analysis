# 面向全局证明的复制尾段路线

本轮没有继续增加有限指数塔层数，而是尝试建立可用于任意层深度的符号引理。
**尚未得到全局不停机证明。** 新推导也尚待独立审查。

## 已取得的进展

1. **完整尾段复制引理。** 对高位精度足够的复制，证明外层会跟随来源行程的整个退出尾段，
   包括其中的不下降步骤。实际 θ=2 的 b/c 复制满足条件。
   来源行程的指针严格更早，因此可用于良基归纳；不必重新展开每个隐藏 k 或平局分支。
2. **偏移复制的碰撞定位。** 偏移为奇数时，在第一个 a 返回处，若来源下一参数大于 1，
   外层直接落到参数 1 并退出。来源参数为 1 时才需要进一步保留相关高位信息。
3. **受控偏移的合并下降。** 在定理 M 已有的早期交叉假设下，对适当受限的有理偏移，
   “b/c 前缀加第一个 a 返回”整体严格下降；整数偏移 −1 获得对数级参数界，
   即使它在单步层面发生平局。
4. **有限尾段版本。** 使用 `Theta=3s+4` 可将同一复制引理用于满足入口条件的结尾阶段，
   以到达单元素状态结束。尚未证明所有真实边界入口都满足该条件。

关键误差递推非常简洁。设两条对应轨道的时间量之差为常量 D，链值之差为 E：

```
a 返回：   E' = 2D - E/2
b/c 返回： E' = (c_X/2^j) E
```

## 全局路径及剩余缺口

[完整推导](PROOF_SHADOW.md) 给出了一项明确的充分条件 CC：
每个大行程在前 `floor(log2 rho)` 条顶层链内结束，或进入可复制整个已完成尾段的状态。
已有基例加 CC 可通过按 rho 的归纳推出 **F 的全局不停机**，但 **CC 尚未证明**。

另一条更具体的推进方向是迭代“受控偏移的合并下降”。当前障碍是：
下降后参数变小，输出余数代表的大小却未必同步变小，现有假设没有封闭。
需要压缩来源表达式或保留合适的祖先信息，而不能只界定当前 `(j,theta)`。

原图灵机还需要补上所有实际边界结尾阶段的安全性，不能把 F 的结论直接当作机器结论。

## 验证

- 3,936 组完整大整数复制运行通过，包含 24 次被复制的不下降转移。
- 363 次精确误差递推核对通过。
- 57 组奇偏移直接退出检查通过。
- 65 组偏移 −1 的合并下降检查通过，包含 8 组单步碰撞。
- 1,312 组构造的有限尾段复制均安全到达单元素状态。

构造状态不被宣称在真实轨道中可达；数值检查用于核对符号推导，不替代全局证明。
