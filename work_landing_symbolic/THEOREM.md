### 3.4 终止：tie→tie 记录律是假的（纠正 1）

gateway Theorem G(ii) 断言 `rho(tie,t+1) >= rho(tie,t) + (m_t−4)`，证明用
“从 `m_t` 走到参数 5 **至少** `m_t−5` 链（每链参数至少降 1）”。**符号错了**：
每链参数**至少**降 1 只能给“**至多** `m_t−5` 链”。正确的直接账本是
`rho(tie,t+1) = rho(tie,t) + 1 + k + E`，其中 `k` 是从块输出到下一个 tie 的链数，
`E = Σε ≥ 0`。若某一步 landing 从 `m_t` 直接到 5，则 `k=1`、`E=0`，记录只增 2。

**精确反例**（`verify_landing.py` 的 `I.*`，`landing_checks.json` 的
`synthetic.tie_record_witness`）：

    (j_p, D_p) = (73515, 98094)   [X(73514) 为奇 a，k_p = 32790]
    参数:  73515 -> 5 -> 17 -> 5 -> 17 -> 17 -> 1
    记录:  73515 -> 6 -> 19 -> 8 -> 21 -> 22 -> 7

第一个块满足 A 型全部假设（`v2(3k_p+D_p)=4`、`v2(M_A)=17 ≤ j_p−3`、块记录
`19 ≤ 73514`），落点类 `21 ≡ 5 (mod 16)`；块输出 `m_0 = 17`；下一个链 `(17, 163774)`
一步 landing 到 `(5,5)`（第二个 tie）。于是
`rho(tie,1) = 8 < 6 + (17−4) = 19`。**断言失败**。

**终止性仍然成立，但要用 Γ-预算**：每条链 `Γ` 至少增加 1（a: +1；b/c: +1+ε），
故任何满足“所有记录 `< min(J,σ)`”的走法满足

    #chains < min(J,σ) − Γ_0,

其中 `Γ_0` 是入口的 Γ。gateway 块数 `T ≤ #chains/2`。这个界**含 J**（通过
`min(J,σ)`）；J-无关的 `T ≤ 36` 只对 36 条代表元走法成立（§3.5）。

**结论**：Theorem G(ii) 的 (R) 不能作为 [A]；其最终 `T ≤ min(J,σ)−rho_0` 只能由
Γ-预算得到（差一个因子 2 的记账），而且仍是 J-依赖的。

### 4.3 O3：局部相位类编码不能覆盖所有类 [A]

## §5 目标定理的精确形式

### 5.1 目标（复述）

输入相位 `θ + s`（`s ∈ Z[1/3]`，实高度 `≤ h`）。要求：着陆类可认证，或经**有限步**
gateway 化解且**每步记录严格下降**，**界不依赖 J**。若只能在附加条件下成立，
逐条写出条件，且条件必须是**来源/相位条件**，不能是参数上界。

### 5.2 Theorem L（J-无关的类决定分支）[A | (L1),(L2)]

**假设**：链 `(j_0, x_0, Θ_0)`，`x_0 = 2^{j_0}u_0`，有理描述 `(C_0,Q_0,b_0)`，
`Q_0 = 3^{r_0}`、`gcd=1`、`ht_0 ≤ h_0`，输入相位 `θ_0+s`；
(L1) 对该走法遇到的每个 a 链 `t`，`(S2*)_t`（或 `(DEPTH)_t` 且 `3Q_t k_t+C_t≠0`，§2.4）；
(L2) 该走法无 `x=0`（x=0 只在 NT 门，已被 (S2*) 排除）；
(L3) 规范小基 `X(0..3)` 全偶（[B]，`Z.small_base_even`）。

**结论**：走法在 `≤ j_0−4` 条链内终止于偶交叉（(L3)）；所有记录 `≤ R_0 = j_0+Γ_0 = J`；
没有 NT 门、没有 gateway；参数/类型序列由 `mod 2^{j_0+1}` 的类逐链决定（直接对
A1/A2/B 的类转移归纳；用 HP 时取 `P=R_0+1`）。**链数界 `j_0−4` 不含 J；记录天花板
`R_0=J` 含 J**。这是本文件能给出的、链数 J-无关的“认证或终止”分支。

**它给出的“认证”**：终止本身就是认证（偶交叉 = epoch 完成）；不需要额外的终端类
证书。若要把分析停在某个 landing 类，则类证书是另一件事（§5.6 S4）。

**缺什么**：(L1) 是沿走法逐链检查的条件，不是从输入相位自动推出的。O1 给出
有界高度下 (L1) 失败的反例；所以 Theorem L **不能**对所有 `θ+s`、所有 h 无条件使用。

### 5.3 Theorem L'（秩/高度受限的 J-无关分支）[A | S1] + [B]

即 §2.8 的 RAT-C。它把 (L1) 变成自动的：`Q_t ∈ {1,3}`、`h_t ≤ 31`（或阈值
`h_t ≤ 841`/`88222`）、b/c 分母 `≤1`、`j ≥ 19/18`。结论：高段记录严格下降，
到 `j ≤ 18`，全残基 [B] 扫描认证，除 24 个例外；界 `j_0−4`，不含 J。
**限制**：秩 ≤1、h ≤31 是对**相位描述**的限制，不是对 J 的上界；但它确实不是
对所有 `s ∈ Z[1/3]`（任意分母深度、任意高度）的定理。

### 5.4 Theorem M（gateway 分支）[A | C1,C2] + [B]

**假设**：(i) 在某个 a 链 (L1) 失败（NT 门）；(ii) 若 `j_t = 5`，3.2 的 gateway
假设（C1,C2）；若 `j_t ≥ 6`，实际仿射来源 `(U,β)` 提供 `u` 的高位。
**结论**：
* `j_t = 5`：显式 gateway 映射（§3.2），块记录 `≤` 前驱记录 `−1`，高度
  `≤ (15+32b)/2 + 3^{-t}(h_0−(15+32b)/2)`（b=0 时 15/2，b=1 时 47/2），
  深度 `r_0+t`，tie 步记录上升 `m−4`。
* `j_t ≥ 6`：输出参数/类不由类决定；需要实际 `u` 或 `β` 的更高位，
  **没有** J-无关的符号处理。
* 终止：只有 `#chains < min(J,σ) − Γ_0`（J-依赖），块数 `≤ #chains/2`。
* **[B]** 36 个显式坏类的代表元走法：后继图无环、最大参数 29、全部终止；
  这不是对任意起点的 [A]，也**没有**记录 ≤ 入口记录的结论（纠正 2）。

若走法来自**整数 θ** 的深段且 `j≥N0+1`、`|θ_rep|≤B−3`，A4 的整数版本给出至多两链
U-无关、记录 `≤J`；一般 `θ∈Z[1/3]` 不适用（§2.7 的反例）。**没有** J-无关的有限步
gateway 界；这是与目标的最大差距。

### 5.5 Theorem N（仿射判据的 J-无关形式）[A-cond] + [B]

即 §2.7 的 A5：无 tie + 终端类已认证 + `σ>J` ⟹ 所有记录 `<σ`，对 U 一致。
**“对 J 无上界”只在终端证书取整数窗口或直接 `certify`（不取 DEEP）时成立**；
DEEP 支另需 `J<T_h`。J 通过 `j=J−Γ`、`σ>J` 与 tie 记录 `J+e` 进入。landing 步
“至多两条链”只在 A4 的整数深段（`j≥N0+1`、`|θ_rep|≤B−3`）下成立；一般情形用 (I) 的
`≤j_0−4` 链或 §3.3 的记录账本。tie 分支的安全条件 `e<σ−J`、续走需 `U mod 2^{e+1}`。
**限制**：终端类证书是 [B] **整数**窗口（有限范围）、DEEP（花 `log* J`，只在 `J<T_h`，
含 R1/R2）、或对该类直接精确走法；`N_Q` 只是续走归约（不是证书，且 `[N0,N_Q)` 开放）。
