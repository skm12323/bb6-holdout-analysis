## §0. 结论先行（本计划的实质判断）

1. **"每步记录严格下降"只在 gateway 块内为真，在 tie 到 tie 之间为假。** 块内：
   `exit record <= predecessor record - 1` [A]（§2.1/§2.2）。tie→tie：
   `rho(tie,t+1) >= rho(tie,t) + (m_t - 4)`，其中 `m_t = v2(M_t) >= 5` 是 gateway 的输出参数 [A]（§3.2）。
   因此重复 gateway 链的 tie 记录**严格递增**，链长 `T` 被 `min(J, sigma)` 预算所界，而**不是**被参数窗口所界。
   这条负面/更正性陈述是本轮要交给协调者的核心事实之一。
2. **两个 gateway（a 型、b/c 型）都能写成同一个类映射**：master 量 `M = x_2 = 2*Theta_5 + 6 - x_5/2`（即参数 5 那一步的下一分子），
   新参数 `m = v2(M)`，新类 `delta' = Theta_5 + 9 - M (mod 2^{m+1})`，新分母 `Q' = 3Q`。Lemma 5.3 的 `Q`
   与 work_claude_shifted §5 的 `Q` 在这个 case **是同一个量**（差在记法 `D_p` vs `theta_T`，以及 Lemma 5.3 写了
   一般的 `k_{j_u-1}`，gateway 时 `k_4 = 1`）。[A]（§2.3）
3. **小参数段是"近似封闭"的（修正）**：一旦参数 `j <= 27`，以后所有参数 `<= 30`（不是 `<=27`：
   NT 失败可把参数抬高最多 3，gateway 步跳到 `m = v2(x_2)`），而 28/29/30 上的类全部认证；
   坏类只有 8 个奇 a 参数上至多 36 个显式类。[A]（§3.3(ii)）
   因此"重复 gateway 链"在结构上被压进一个有限图；链长是否 J-无关，等价于这个有限图有没有环。
   这是**可判定**的有限问题（§3.4 / §4.4），不是"再扩大扫描"。**实测：36 个顶点、4 条边、无环。**
4. **O1 只在深部 gateway 处出现，不在重复链内部出现**：O1 的失败要求 `M ≡ 0 mod 2^{sigma-1}`；小参数段里
   `|M| <= 2^{28} << 2^{sigma-1}`，故该条件自动成立。危险类（O1 的 3-adic 轨道）与入口深度 `r_0` 及祖先精度 `sigma`
   相关，是**来源/相位条件**，不是参数上界。[A]（§5）
5. **不能证明的东西（如实写）**：tie 记录递增只给 `T <= sigma`、来源预算只给 `r_0 <= sigma_W`（合起来最好
   `2*sigma` 量级），而 O1 的失败阈是 `r_0+T >= (5/8)(sigma-53)`——差因子 > 3。所以"深度-精度关联"
   是真正需要的外部条件（SC），本轮不声称它自动成立。

## §1. 记号与导入

### §1.1 链与记录（沿用已接受约定）

链 `(j, Theta, x)`，`x = 2^j u`（u 奇），`n = j-1`，读交叉 `X(n)`。
a 步（`tau(n) = 2k`）：`x' = 2*Theta + 6k - x/2`，`Theta' = Theta + 3 + 6k`，`j' = v2(x')`。
b/c 步：`x' = c'_W u + lambda'_W`，`j' = omega(n) = v2(lambda'_W)`，`Theta' = Theta + 3 + 3*tau(n)`。
缺陷 `D = Theta - x`；`theta = D mod 2^{j}`（symmetric 代表写 `D ≡ theta (mod 2^j)`）。
记录 `r = j + Gamma`，`Gamma` 累计 `1+eps`（a 步 `eps=0`，b/c 步 `eps = n - v2(c'_W)`）。
`certify(j, delta)`：从代表元 `(2^j, 2^j+delta)`（精度 `j+1`）出发的精确走法无 `x=0`、终止、所有记录 `<= j`
（work_claude_shifted Prop 3.2）。`Bad_j = {delta mod 2^{j+1} : certify(j,delta) = false}`。

### §1.2 有理模式描述（本轮"输入相位 theta+s"的载体）

`D ≡ C/Q + b*2^j (mod 2^{j+1})`，`Q > 1` 奇，`gcd(C,Q) = 1`，`b in {0,1}`（ODD_DENOMINATOR §1 [A]）。
**高度** `h = |C|/Q`（实数，不是对称余数的大小）；**深度** `r` 定义为 `Q = 3^r`（本轮只关心这一族）。
源移位 `s = Phi - 2 = -1 - lambda_Y in Z[1/3]`，`|s| <= h`；`s in {0,-1,+1}`（eps=3 / AA / BA）
或 `s = +4/3`（BBBAA，BBBAA_COPY_CERTIFICATE §4）等等，本轮把 `s` 当参数
（`CONGRUENCE_TARGET_NOTE.md:249-255` 的 `s(n) := -1-lambda_Y(n) mod 2^{omega+1}`）。
**注意**：描述是 2-adic 类的一个名字（`C/Q` 指 `C*Q^{-1} mod 2^{j+1}`）；类本身是整数，
"高度"与"对称余数大小"是两个不同的量。这一点贯穿全文。

## §2. 两个 gateway 的类映射（ask G1）

### §2.1 类型 A 的精确恒等式 [A]

设前驱 `(j_p, Theta_p, x_p)`，`x_p = 2^{j_p} u_p`，`D_p = Theta_p - x_p`，a 步半时 `k = k_p = tau(j_p-1)/2`。
记 `x_5 = 2*Theta_p + 6k - x_p/2`，`Theta_5 = Theta_p + 3 + 6k`，再走参数 5 的 a 步（`k_5 = 1`）：

```
x_2    = 2*Theta_5 + 6 - x_5/2
       = M_A + x_p/4 ,          M_A := Theta_p + 12 + 9k               (A1)
D_2    = -3k - x_p/4 ,                                                (A2)
Theta_2= Theta_p + 12 + 6k .                                          (A3)
```

由 (A1)：`M_A ≡ theta_p + 12 + 9k (mod 2^{j_p})`；若 `v2(M_A) <= j_p-3`，则
`j_2 = v2(M_A)`，且由 (A2) `x_p/4 = 2^{j_p-2}u_p ≡ 0 (mod 2^{j_2+1})` 得

```
delta_2 := D_2 mod 2^{j_2+1} = (-3k) mod 2^{j_2+1} .                  (A4)
```

**精度前提**：`delta_2` 需要前驱缺陷 mod `2^{j_2+1}`（不是只 mod `2^{j_p}`）；因为 `j_2 <= j_p-3`，
前驱类 mod `2^{j_p+1}` 就够。**警告**：`delta_2 != 3 - theta_5`——参数 5 那步的 `-x_5/2 = -16u_5`
不是类的函数，所以 gateway 必须用显式 `M`，不能用 a-map 的反射。这是本方向与
"θ̃-游走"最容易混淆的一处，脚本必须单独测。

**记录**：`rho_2 = j_2 + Gamma_p + 2 <= (j_p-3) + Gamma_p + 2 = rho_p - 1`。 [A]

### §2.2 类型 B 的精确恒等式 [A]

前驱 `(j_p, Theta_T, x_T)`，`x_T = 2^{j_T}u_T`，b/c 步 `x_5 = c' u_T + lambda'`，`Theta_5 = Theta_T + 3 + 3*tau`，
`sigma = v2(c') = n_T - eps`。再走参数 5 的 a 步：

```
M_B   := 2*D_T + 12 + 6*tau(n_T) - lambda'_W(n_T)/2                   (B1)
       (= 2*theta_T + 12 + 6*tau - lambda'_W/2  mod 2^{j_T+1})
x_2    = M_B + u_T*(2^{j_T+1} - c'_W/2) ,                             (B2)
D_2    = Theta_5 + 9 - x_2 ,                                          (B3)
```
**（实现后修正）(B1) 不能用 `Theta_T` 写**：`2*Theta_T = 2^{j_T+1}u_T + 2*D_T`，`2^{j_T+1}u_T` 必须留在
(B2) 的修正项里；写成 `2*Theta_T+12+6*tau-lambda'/2` 会让 (B2) 差 `u_T*2^{j_T+1}`（脚本 I5 首版即此错误）。
`v2(c'_W/2) = sigma-1`，`v2(2^{j_T+1}) = j_T+1 > sigma-1`。若 `v2(M_B) < sigma-1`，则
`j_2 = v2(M_B) < sigma-1`，且（`j_2+1 <= sigma-1`）

```
delta_2 ≡ Theta_5 + 9 - M_B ≡ theta_T + 6 + 3*tau(n_T) + 3*tau(j_u-1) - M_B (mod 2^{j_2+1}),
```
其中 `j_u = omega(n_T)`（gateway 时 `= 5`，`tau(j_u-1) = tau(4) = 2`）。   [A]
记录：`rho_2 = j_2 + Gamma_T + 2 + eps_T <= (sigma-2) + Gamma_T + 2 + eps_T`，
而 `sigma = j_T - 1 - eps_T`，故 `rho_2 <= j_T + Gamma_T - 1 = rho_T - 1`。   [A]
（与 work_r1r2 Lemma 5.3 的 `r_{u+1} <= r_T-1` 一致；本文的 `j_u=5` 特化。）

### §2.3 Lemma 5.3 的 Q 与 work_claude_shifted §5 的 Q：同一个量 [A]

两者都是 `x_2` 的两个写法，且都由 `3D_2 = 9 + 6k_5 - D_5 - x_2`（k=1 时即 `15 - D_5 - x_2`）导出：

| 出处 | 表达式 | 条件 | 差别 |
|---|---|---|---|
| work_claude_shifted §5 (a) | `theta_p + 12 + 9k` | a 步入 5 | 原文写 `D_p + 12 + 9k + 5*2^{j_p-2}u_p`；后项被 `M_A` 吸收 |
| work_claude_shifted §5 (b/c) | `2D_p + 12 + 6*tau - lambda'/2` | b/c 步入 5 | `D_p` 精确 |
| work_r1r2 Lemma 5.3 | `2*theta_T + 6 + 6k_{j_u-1} + 6*tau - lambda'/2` | 任意 odd-a 落点 `j_u` | 一般 `k'` |

`j_u = 5` 时 `k_4 = 1`，第三个式子成为 `2theta_T + 12 + 6tau - lambda'/2`，与第二个**逐项相同**；
第一式的 `D_p` 换成 `theta_T` 的差别是 `2(D_p - theta_T) ≡ 0 (mod 2^{j_T+1})`，而 `j_2 < sigma-1 <= j_T-2`，
故 `v2` 与 `delta_2` 都不变。**结论：是同一个量**；Lemma 5.3 是它的"落点参数不限于 5"的推广，
work_claude_shifted §5 是 `j_u = 5` 的实例。所谓"分母 Q"是另一个东西（2.4），本文用 `M` 表示这个整数，
以免与有理模式的分母 `Q` 混淆。

### §2.4 新分母、高度、lift 位 [A]

参数 5 的那一步（`D_5 ≡ C/Q + b*2^5`）用 `3D_2 = 15 - D_5 - x_2` 与 `x_2 = 2^m*(odd)`：

```
D_2 ≡ (15Q - C)/(3Q) + 2^m  (mod 2^{m+1}),   m = v2(x_2)              (D1)
```
（`-x_2/3 ≡ 2^m (mod 2^{m+1})`，因 `x_2/2^m` 与 `3^{-1}` 都奇。）约分后分母 ∈ {Q, 3Q}；
`Q = 3^r` 时 `3 ∤ (15Q - C)`，**必为 3Q**。高度：`|(15Q-C)/(3Q)| <= 5 + |C|/(3Q)`。
`b' = 1`（输出 lift 位），随后的强下降把它清零（`2^m` 在更低精度下消失）。
—— 与 ODD_DENOMINATOR §3 完全一致；本文把它接到"重复链"上（§3）。

### §2.5 精度来源（与 O2 的接口）[A]

`delta_2` 需要前驱缺陷在 `2^{m+1}` 上的信息。gateway 情形 `m <= min(j_p-3, sigma-2)`，而前驱类是
mod `2^{j_p+1}`（或更好）已知的，故够用；但 (B3) 的 `Theta_5` 与 `M_B` 都是**实际状态的显式整数**，
不是类的函数（`M_B` 里的 `D_T` 只用到 mod `2^{j_T+1}` 的类）。因此：**类数据足够，但必须带足够精度**；
在 `S(J)` 里这由实际仿射来源提供（O2 的 `x = A*U + beta`），本计划的公式把这一点写成显式前提
"前驱类已知 mod `2^{m+2}`"。

## §3. 迭代（ask G2、G3）

### §3.1 递推 [A]

设 `t = 0,1,...,T-1` 标记第 `t` 个 gateway 块，`(j_t, delta_t, C_t, Q_t, Lambda_t)` 为块后状态。则

```
Q_t = 3*Q_{t-1} = 3^{r_0 + t},   C_t = 15*Q_{t-1} - C_{t-1}   （Q=3^r 时 gcd(C_t,Q_t)=1，不约分）
j_t = v2(M_{t-1})  （A 型：M = theta_{t-1}+12+9k；B 型：M = M_B）
delta_t = Theta_5^{(t-1)} + 9 - M_{t-1}  mod 2^{j_t+1}
Lambda_t = Lambda_{t-1} + 2 + eps_{t-1}
```
（`c_t = C_t/Q_t = 5 - c_{t-1}/3` 与 `Q_t = 3Q_{t-1}` 一致；`15Q-C` 与 3 互素由 `gcd(C,Q)=1`、`Q=3^r` 保证。）
高度递推（把 b/c 步的移位 `s = Phi-2` 计入）：
`h_t <= 5 + (h_{t-1} + |s_{t-1}|)/3`，故 `|s| <= h` 时 `h_t <= max(h_0, 15)`，**与 t 无关** [A]。
（`|s| <= 1` 的整数移位给出固定点 8；BBBAA 的 `4/3` 给 15 以下。）

### §3.2 记录：块内降、tie→tie 升 [A]

块内：§2.1/§2.2 的 `rho_2 <= rho_p - 1`。
tie→tie：设 tie `t` 在参数 5，记录 `rho(tie,t) = 5 + Lambda_t`；块后记录 `m_t + Lambda_t + 1`；
从 `m_t` 走回参数 5 **至少** `m_t - 5` 链（每链参数至少降 1）、每链 `Lambda` 至少 +1，故
```
rho(tie,t+1) >= rho(tie,t) + (m_t - 4),   m_t >= 5.                  (R)
```
于是 `rho(tie,t)` 严格递增，`T <= min(J, sigma) - rho(tie,0)`。
**这更正了"重复 gateway 每步记录严格下降"的朴素读法**：每块相对其前驱下降，但相对上一个 tie 上升。
它同时是好事：tie 记录递增正是"链长被精度/记录预算所界"的机制（§5）。

### §3.3 终止判据：精确同余 [A]

**（i）已知认证集**（可直接用，[B]）：
- `5 <= j <= 27`：`Bad_j` 显式（§1.4）；`delta ∉ Bad_j` 即闭合。`X(j-1)` 奇 a 时坏类是**首链 tie 类**

## §5. O1 作为"重复链无限/长"的危险类（ask G5）

### §5.1 轨道 = 复合映射的迭代 [A]

- 纯 gateway 映射 `c -> 5 - c/3`（不动点 `15/4`）；`5 -> 10/3`，**正是 BBBAA 的源相位**
  （BBBAA_COPY_CERTIFICATE §4：`c_new = c_p + 4/3`，源 `Phi = (10-2^m)/3`）。
- gateway + 一次 a 下降：`c -> c/3 - 2`（不动点 `-3`），`t` 次迭代 `c_t = -3 + (c_0+3)/3^t`；
  `c_0 = 5` 给 `c_t = -3 + 8/3^t`，**即 O1 的轨道**（ODD_DENOMINATOR §3 的 consistency check）。
- tie 类保持：`c ≡ 5 (mod 16) ⇒ c/3 - 2 ≡ 5 (mod 16)`（`5/3 ≡ 7`），故轨道**永不离开** tie 类；
  纯 gateway 映射则不保持（`5 -> 10/3 ≡ 14 mod 16`）。
- 高度沿轨道 `<= 5.67`，**有界**。这正面复述 O1 的负面结论：高度有界不能排除危险类。

### §5.2 O1 阈的精确形式与重推 [A]

O1（P=49 源，`sigma = 1051689726214394`，`y = 16A+10`，`A = 263882790666247 ≡ 7 mod 8`）：
移位 `eta_r = c_r - 2 = -5 + 8/3^r`，首输出 `y_r = 16(A + 3^{-r})`，
`v2(y_r) = 4 + v2(A*3^r + 1)`；首个 a 步耗 1 位精度，故 `v2(A*3^r+1) >= sigma-5` 是严格安全失败的一个充分条件（O1 用的判据）。
由 `A+1 < 2^48`、`3^5 < 2^8`：`(A*3^r+1)^5 < 2^{240+8r}`，于是失败 ⇒ `5(sigma-5) < 240+8r` ⇒
```
r > 5*(sigma-53)/8.                                                    (O1S)
```
本轮重推（与 O1 §4 一致）：失败 ⟹ (O1S)；故 `r < 5(sigma-53)/8` ⟹ 首输出安全。
**注意这只是首输出的充分条件**；整条尾还要别的东西。

### §5.3 排除它的来源条件（不是参数上界）

O1 的失败是**同一类**失效：一个 a 步的分子在 `2^{sigma-1}` 上消失，使新参数 `>= sigma-1`、记录 `>= sigma`；
在 gateway 语言里就是 `M ≡ 0 (mod 2^{sigma-1})`，即 Lemma 5.3 / work_claude_shifted §5 的 valuation 假设失效，
**深部前驱**的 gateway 无法化解。因此：

- **精确条件（同余型）**：`v2(A*3^{r} + 1) < sigma - 5`，等价于危险剩余类
  `3^r ≢ -A^{-1} (mod 2^{sigma-5})` 的排除。这是**来源/相位条件**（A、sigma 来自源，r 来自相位深度）。
- **尺寸型充分条件**：`(SC)  r_0 + T < 5*(sigma-53)/8`。`sigma` 是祖先的系数精度（来源量），
  `r_0 + T` 是进入相位与实际链的分母深度（相位/轨迹量）。**不是 J 的上界**，也不是任何固定参数窗。
- **如实报告的负面结论**：记录预算只给 `T <= sigma - rho_0`（每块至少 1 单位记录）；`r_0` 只能由**来源自身**
  的预算 `sigma_W` 界住（`r_0 <= sigma_W`）。合起来最好也只是 `r_0 + T <= r_0 + sigma` 的量级（与 `2*sigma` 同阶），
  而 (SC) 要的是 `0.625*sigma`：**弱因子 > 3**。所以 (SC) **不能**由现有预算推出；它是本轮必须外置的附加条件，
  也正是 O1 要求的"r 与 sigma 的关联"。
- **正面结论**：小参数段（`j <= 27`）里 `|M| < 2^{28} << 2^{sigma-1}`，valuation 假设自动成立，
  故 **O1 型危险只可能在第一个（深）gateway 处出现，重复链本身不制造新的 O1 危险**；
  它只把 `r` 从 `r_0` 推到 `r_0 + T`。

## §7. Falsification tests（什么结果会杀死上面的陈述）

1. **A1/A2/A4 的反例**：任何合成或规范实例上 `x_2 != M_A + x_p/4`、`D_2 != -3k - x_p/4`、

2. **B2/B3 的反例**：`x_2 != M_B + u_T(2^{j_T+1} - c'_W/2)`，或 `delta_2` 依赖 `u_T`（同一前驱类的两个
   不同 `u_T` 给出不同的 `delta_2`）。→ 杀死 §2.2 的"类已确定"。
3. **记录反例**：存在 gateway 块使 `exit record >= entry record`（在 valuation 假设下）。→ 杀死 §2.1/§2.2 的记录部分。
4. **分母反例**：`Q = 3^r` 时约分后分母不是 `3Q`，或 `Q' != 3Q`。→ 杀死 §2.4/§3.1。
5. **tie→tie 反例**：`rho(tie,t+1) - rho(tie,t) < m_t - 4`。→ 杀死 (R)，进而杀死 §3.2 的长度机制。
6. **小参数封闭反例**：出现 `j <= 27` 之后参数 `> 27`（例如某个 gateway 输出 `m = 28`）。→ 杀死 §3.3(ii)。
7. **坏图有环且可达**：36 个坏类里存在环，且环上每个类的 `certify` 都失败（即环是真实的类级周期）。
   → 杀死 §6(iv) 的"`<= 36` 块闭合"；此时必须改用 §3.4(b) 的表述并把环写成来源条件。
8. **规范反例**：X(6132) 之外的某个规范 `omega = 5` tie 入口，经 gateway 后输出类仍 `≡ 5 mod 16`
   （即规范数据里出现第二代 tie）。→ 杀死"规范数据 T=1"的经验陈述（agent_C 的 [B]），并给出真正的重复链实例。
9. **轨道恒等式反例**：`c_t != -3 + (c_0+3)/3^t`，或 `c ≡ 5 mod 16` 不保持，或 `5 -> 10/3 mod 16` 不对。
   → 杀死 §5.1。
10. **O1 阈反例**：存在 `r < 5(sigma-53)/8` 但 `v2(A*3^r+1) >= sigma-5` 的实例。→ 杀死 §5.2 的充分方向
    （注意：本轮的推理只处理该阈值；反例需要 `(A3^r+1)^5 >= 2^{240+8r}` 与 valuation 同时成立，理论上可能对
    某些 `A` 发生，届时阈值里的常数 `240`（来自 `|A| < 2^48`、`3^5 < 2^8`）需按真实 `|A|` 重算）。
