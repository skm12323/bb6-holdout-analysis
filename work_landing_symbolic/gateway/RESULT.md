## 2. 证明骨架（关键恒等式行内给出）

**(i) A 型。** 记 `x_5 = 2*Theta_p + 6k - x_p/2`、`Theta_5 = Theta_p + 3 + 6k`。参数 5 的 a 步（`k=1`）：
```
x_2 = 2*Theta_5 + 6 - x_5/2 = Theta_p + 12 + 9k + x_p/4 = M_A + x_p/4
D_2 = Theta_2 - x_2 = (Theta_p + 12 + 6k) - (Theta_p + 12 + 9k + x_p/4) = -3k - x_p/4
```
`x_p/4 = 2^{j_p-2}u_p`；若 `v2(M_A) <= j_p-3` 则 `2^{j_2+1} | x_p/4`，故 `j_2 = v2(M_A)`、`delta_2 = -3k`。
记录：`rho_2 = j_2 + Gamma_p + 2 <= (j_p-3) + Gamma_p + 2 = rho_p - 1`。

**(i) B 型。** `x_5 = c'u_T + lambda'`、`Theta_5 = Theta_T + 3 + 3*tau`，且 `2*Theta_T = 2^{j_T+1}u_T + 2*D_T`：
```
x_2 = 2*Theta_5 + 6 - x_5/2 = [2*D_T + 12 + 6*tau - lambda'/2] + u_T*(2^{j_T+1} - c'/2)
    = M_B + u_T*(2^{j_T+1} - c'/2)
```
修正项 valuation `= v2(c'/2) = sigma - 1`（因 `sigma-1 < j_T+1`）；`v2(M_B) < sigma-1` 时 `j_2 = v2(M_B)`。
`Theta_2 = Theta_5 + 9`，`x_2 ≡ M_B (mod 2^{j_2+1})`，故 `delta_2 = Theta_5 + 9 - M_B`。
记录：`rho_2 = j_2 + Gamma_T + 2 + eps_T <= (sigma-2) + Gamma_T + 2 + eps_T = j_T + Gamma_T - 1 = rho_T - 1`
（用 `sigma = j_T - 1 - eps_T`）。

**(i) 分母/高度。** 参数 5 的 a 步的恒等式 `3D_2 = 9 + 6k - D_5 - x_2`（`k=1` 即 `15 - D_5 - x_2`），
`-x_2/3 ≡ 2^{m} (mod 2^{m+1})`（`m = v2(x_2)`），故 `D_2 ≡ (15Q-C)/(3Q) + 2^m (mod 2^{m+1})`。
`Q = 3^r` 时 `15Q-C` 与 `3Q` 互素，约分后分母恰为 `3Q`；实高度 `|5 - c/3| <= 5 + |c|/3`，
连同 b/c 步的移位 `s`：`h' <= 5 + (h + |s|)/3`。

**(ii)** 每块 `Q -> 3Q`，故深度 `r_0+t`。设 tie `t` 的记录为 `5 + Lambda_t`；块后状态在 `m_t`，记录 `m_t + Lambda_t + 1`。
从 `m_t` 走到参数 5，每链参数最多降 1（a 步 `j' >= j-1`、b/c 步 `j' <= j-2-eps`），故至少 `m_t - 5` 链、
`Lambda` 至少加 `m_t - 5`；于是下一 tie 记录 `>= 5 + Lambda_t + 1 + (m_t-5) = rho(tie,t) + (m_t-4)`。
复合 `c -> 3 - (5 - c/3) = c/3 - 2` 的直接计算给出 `c_t = -3 + (c_0+3)/3^t`。

**(iii)** b/c：`omega <= log2 lambda'`；非 gateway a 步：`x' = 1.5x + 2D + 6k`，
`|x'| <= 1.5*2^j*u + 2*2^{j+1} + 6k < 2^{j+4}`（`u <= 5`、`k <= 10`）⇒ `j' <= j+3`。
gateway 步：`m = v2(M)`，`|M| <= 2|theta| + 6*tau + lambda'/2 + 12`。
`Bad_6 = empty` + `X(28)`、`X(29)` 偶 ⇒ 28/29/30 全部认证。

**(iv)** 36 个坏类逐一代入精确走法，取第一个坏后继；图无环（本轮实测）。
`(5,5)` 的走法：`x=32, Theta=37 -> x'=64 (j=6), Theta'=46 -> X(5) 为奇 b, omega=1 -> j=1` 结束，记录 `max = 7`。

**(v)** O1 阈：`y_r = 16(A + 3^{-r})`、`v2(y_r) = 4 + v2(A*3^r+1)`；失败（`v2 >= sigma-5`）⇒
`(A*3^r+1)^5 >= 2^{5(sigma-5)}`，而 `(A+1)^5 < 2^{240}`、`3^5 < 2^8` 给 `(A*3^r+1)^5 < 2^{240+8r}`，
故 `5(sigma-5) < 240+8r`，即 `r > 5(sigma-53)/8`。本轮用精确整数验证 `(A+1)^5 < 2^{240}`、
`r_min = 657306078883964`（与 O1 一致）且阈在 `r_min-1` 严格、在 `r_min` 不成立（恰好紧）。

* **(C4) 深度–精度关联（O1）。** `(SC)`：`r_0 + T < 5*(sigma-53)/8`，或精确同余
