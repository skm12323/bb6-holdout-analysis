## 1. R1：正规形与精确步进引理

### 1.1 证书（定义）

链状态 `(j, x, Theta)`，`x = 2^j u`，`u` 奇，`n = j-1`，读交叉 `X(n)`；
缺陷 `D := Theta - x in Z`。**有理证书**是三元组 `(C, Q, b)`：

    Q = 3^r (r>=0),  gcd(C,Q) = 1,  b in {0,1},
    D ≡ C*Q^{-1} + b*2^j   (mod 2^{j+1}).                                  (NF)

记 `c := C/Q`，**实高度** `ht := |C|/Q`，**秩** `r`，**中心高度** `A := |c - 3/2|`。
`C*Q^{-1}` 指 2-adic 逆（Q 奇，故可逆）；(NF) 等价于 `Q(D - b*2^j) ≡ C (mod 2^{j+1})`。

**三条结构性注意**（[A]）：

* (N1) **类与 lift 分离**：类 `delta := D mod 2^{j+1}` 是状态的不变量；`(C,b)` 只是它的一个
  "名字"。同一个类有 `(C,b)` 与 `(C - Q*2^j, 1-b)` 两个相邻名字，以及 `(C + Q*2^{j+1}t, b)`
  无穷多个 lift。**高度不是类的函数**（这正是 ODD_DENOMINATOR 审阅 E2/E5 与 O3 的要点）。
* (N2) **Q 可以大于 2^j**：`C` 只需给到 `mod 2^{j+1}Q` 就决定类；`C in [-hQ,hQ]` 在
  `2h < 2^{j+1}` 时对每个类至多一个 lift。所以"Q 大于 2^j"不需要特殊代表元：
  递推 `C -> ...` 直接作用在所选整数 C 上，模数信息只需 `mod 2^{j'+1}Q`（见下）。
  唯一的实际问题是**选择规则**：高度/秩的递推只对所选 lift 成立；换 lift 就换高度。
* (N3) 类与精度：由类只能得到 `P = j+1` 位的初始一致性（HP 的 P）。要更多位（更宽的记录预算）
  必须用实际来源（affine beta），这是 O2 的正题。

### 1.2 引理 A（a 步三分类）[A]

设 `tau(n) = 2k`，`p := 1 + v2(3Qk + C) = 1 + v2(3k + C/Q)`（后者为 2-adic 估值；
`3Qk+C=0` 时约定 `p=+inf`，只有 Q=1 可能）。四种情形：

* **(A1) 强下降 `p <= j-2`**：`j' = p`，`C' = 3Q - C`，`Q' = Q`，`b' = 0`，
  且新证书满足 `D' ≡ C'*Q'^{-1} (mod 2^{j'+1})`。
* **(A2) 一步下降 `p >= j`**：`j' = j-1`，`D' ≡ 3 - D - 2^{j-1} (mod 2^j)`，`b'=0`。
  类仍由旧类决定（因为 u 奇 1 位就够），但**低高度 lift 被破坏**：自然 lift 的高度增加 `2^{j-1}`。
* **(A3) NT 门 `p = j-1`**：`v2(x') >= j`，故 `j' >= j`；`j'` 的精确值**不由类决定**。
* **(A4) 排除**：`x' != 0` 对一切 `Q>1`（任何情形）；`Q=1` 时 `x'=0` 可能（虚拟共振）。

证明（A1）：`x' = (3/2)x + 2D + 6k = 3*2^{j-1}u + 2(CQ^{-1}) + 6k + b*2^{j+1} + 2^{j+2}m`。
令 `y := 3*2^{j-1}u + 2CQ^{-1} + 6k`，则
`Q*y = 2(C+3kQ) + 3*2^{j-1}uQ`；第一项 valuation 为 `p`，第二项为 `j-1`；
`p <= j-2 < j-1` 给出 `v2(y) = p`，而 `b*2^{j+1}` 与 `2^{j+2}m` 的 valuation `>= j+1 > p`，
故 `v2(x') = p`。又 `D' = 3 - D - x/2`，模 `2^{j'+1}` 时 `b*2^j`、`2^{j+1}m`、`2^{j-1}u`
（后者因 `j-1 >= j'+1`）全部消失，故 `D' ≡ 3 - CQ^{-1} = (3Q-C)Q^{-1} (mod 2^{j'+1})`。
(A2)：`p>=j` 给出 `2^{j-1} | (3k+CQ^{-1})`，故 `x' = 2^{j-1}(3u + 2z)`（`z in Z_2`），
`3u+2z` 奇，`j'=j-1`；`D' = 3-D-2^{j-1}u ≡ 3-D-2^{j-1} (mod 2^j)`（`u` 奇）。
(A3)：`v2(3k+CQ^{-1}) = j-2`，`x' = 2^{j-1}(3u+w)`，`w` 奇，`3u+w` 恒偶，故 `j' >= j`，
再往下的 `v2(3u+w)` 由 `u mod 4` 与 `w mod 4`（后者由类决定）共同决定，故类不够。
(A4)：`x'=0` 给 `Q*y = 0`（在 Z 中），即 `2C = -3Q(2k+2^{j-1}u)`，故 `Q | 2C`，
`Q | C`，与 `gcd(C,Q)=1, Q>1` 矛盾。`Q=1` 的反例：`D = -3x/4-3k`（如 j=5,u=1,k=1,D=-27）。

**本轮已跑的内联抽查**（`python -B -c`，精确整数，未写脚本）：
`Q in {1,3,9,27,81,3^20}`, `C in [-25,25]` coprime, `j in {5,6,9,13,21,40,70}`,
`u in {1,3,5,17}`, 两个 lift, `b in {0,1}`，共 **7,264** 次 a 步：
A1 的 `v2(x')=p` 与类同余 `Q D' ≡ 3Q-C (mod 2^{p+1})`、A2 的 `j'=j-1` 与
`D' ≡ 3-D-2^{j-1} (mod 2^j)`、A4 的 `x'!=0`，**0 失败**（我第一次用 `min(p,j-1)` 预测时在
`p=j-1` 处得到 24 个"失败"，全部是 A3 边界——这正是分界，不是反例）。A3 的 u 依赖：
同一类 `(j=5,Q=1,C=-11,b=0)` 在 `u=1,3,5,17` 下给出 `j' = 5,6,7,8`。
`Q in {3,...,3^12}`, 5,600 次无 `x'=0`。**这些只是内联抽查，正式脚本见 §7（[P]）。**

### 1.3 引理 B（b/c 步与有理位移）[A]

设 `j = n+1`，交叉 X(n) 为奇 b/c，`sigma := v2(c'_W(n)) = n-eps`，`omega := v2(lambda'_W(n))`，
S1：`omega < sigma`。则精确地

    D' = D + Phi - 2 + (2^j - c'_W) u,     Phi := 3*tau(n)+5 - lambda'_W(n) = 1 - lambda_Y,
    j' = omega <= j-2-eps,     v2(2^j - c'_W) = sigma,

故 `D' ≡ D + Phi-2 (mod 2^{j'+1})`，从而类满足

    D' ≡ c + (Phi-2)   (mod 2^{j'+1}),     C' ≡ C + Q*s   (mod 2^{j'+1}Q),   b' = 0,   (RB)

其中 `s` 是 `Phi-2` 在模 `2^{j'+1}` 下的**所选代表**。`s in Z[1/3]` 一般；写 `s = a/3^d`
（`gcd(a,3)=1`）则

    Q' = 3^{max(r,d)},   C' = C*3^{max(0,d-r)} + a*3^{max(0,r-d)},   gcd(C',Q')=1.      (RB2)

**代表的选择**（关键，见 §0.7）：`C'/Q'` 不是唯一确定的，`C'` 只定到 `mod 2^{j'+1}Q`。
低高度/低秩的代表必须按 O3 的代价 `2r + ceil(max(0,1-c,c-2))` 取最小者，或由来源直接给出。
两个必须写清的实例：

* `eps=3`（history A）：accepted 恒等式 `delta' ≡ theta (mod 2^{q+1})` 即 `Phi-2 ≡ 0 (mod 2^{j'+1})`，
  故选 `s=0`，`C'=C`，`Q'=Q`，**高度不增**。注意整数 `Phi-2` 可以很大：
  规范 c 交叉 `n=65` 的 `Phi-2 = -80`，但 `omega=3`，`-80 ≡ 0 (mod 16)`。
  所以"`C' = C + Q*(Phi-2)`"作为整数递推是错的；正确的是模 `2^{j'+1}` 后取代表。
* `eps=5`（AA/BA）：`s = -1`（AA、b）或 `+1`（BA），`C' = C -/+ Q`，`Q'=Q`。
* `eps=11`（BBBAA）：`s = +4/3`，故 `Q=1` 时 `Q'=3`、`C'=3C+4`（秩 0->1）；`Q=3^r (r>=1)` 时
  `Q'=Q`、`C'=C+4*3^{r-1}`（秩不变）。

### 1.4 引理 C（参数五 gateway）[A]

    D' ≡ (15Q - C - 32bQ)/(3Q) + 2^m   (mod 2^{m+1}),     即

## 2. R2：高度、秩与记录递推

### 2.1 中心高度不变量 [A]

`A_t := |c_t - 3/2|`。a 步：`c' = 3-c`，故 `A' = A` **精确保持**。
b/c 步：`c' = c + s`，故 `A' <= A + |s|`。

**与 JOINT_HEIGHT_BUDGET 的关系**（[A]，本轮推导）：O3/JOINT 的高度
`h(c) = ceil(max(0,1-c,c-2))` 满足恒等式 `h_pen(c) = max(0, A - 1/2)`
（`h_pen := max(0,1-c,c-2)`）。故 `W = Gamma + j + 2r + h_pen` 中的 `h_pen` 正是 `A` 的
"到区间 [1,2] 的距离"，而 `A` 是 a 步的精确不变量。**这是本方向与已接受 W 记账的接口**：
我的 (DEPTH) 条件就是 W 里 `2r + log2(kappa+h)` 那部分不超过参数 `j`。

### 2.2 低亏损步的高度 [A]

`b` 步：`s=-1`。`BBBAA`：`s=+4/3`，`A' <= A+4/3`。

### 2.3 gateway 的高度与不动点（修正 ODD_DENOMINATOR §3）[A]

由 (GWH)：`ht' <= 5 + ht/3 + 32b/3`。

* `b=0`：`h -> 5 + h/3`，不动点 **15/2 = 7.5**（与 ODD §3 一致）。
* `b=1`：`h -> 5 + 32/3 + h/3`，不动点 **47/2 = 23.5**（ODD §3 未含 32/3 项，需修正）。
* t 步 gateway（连续 `b=1` 的最坏情形）：`ht_t <= 47/2 + 3^{-t}(h_0 - 47/2)`。

同一 gateway 还给出记录：`R' = m + Gamma + 1` 对比 `R = 5 + Gamma`，故
**`R' <= R` 当且仅当 `m <= 4`**；`m=4` 时相等且走法在下一链终止（j<=4 即偶交叉）。

### 2.4 秩递推 [A]（**已按实现阶段的反例修正**）

* a 步 A1（反射描述）：`r' = r`。
* a 步 A2（一步下降，catapult 描述）：`r' = r+1`；经 3-约分后 `r' <= r+1`（可更小）。
* b/c 步（位移 `s=a/3^d`，未约分 `Q2_raw = 3^{max(r,d)}`，`C2_raw = C*3^{max(0,d-r)} + a*3^{max(0,r-d)}`）：
  **`r' <= max(r,d)`**，且 `r' = max(r,d)` 当且仅当 `3 ∤ C2_raw` 或 `max(r,d)=0`；
  约分可一次降不止 1（`C2_raw=0` 时降到 0）。
* gateway：`r' = r+1`（`r>=1`；此时必有 `3 ∤ C'`）；`r=0` 时 `r'=1`，除非 `C+2b ≡ 0 (mod 3)`（则 `r'=0`）。
* 所以：**秩只在 A2/NT 门/gateway（或非整位移的 c 步）增长**；A1/b/低亏损 c 步不增长；
  `BBBAA` 的 `+4/3` 是 rank 0->1。
* 修正来源：`verify_rational.py` 在 4,032 个合成 b/c 与 9,120 个规范 b/c 上发现
  `r' = max(r,d)` 作为等式不成立（例如 `Q=9, C=55, s=2/9`：`57/9 -> 19/3`，秩 2->1；
  `Q=9, C=1, s=-1`：`C2_raw=0`，秩 2->0）。改为上面的 `<=` 形式后 0 失败。
  这也影响 `(RB2)` 的表述：`Q' = 3^{max(r,d)}` 应理解为**未约分**形式，最终秩取约分后的。

### 2.5 记录递推 [A]

`R_t = j_t + Gamma_t`。逐类：强下降 `R' <= R-1`；b/c `R' <= R-1`（因 `omega<=j-2-eps` 且

所以**记录只有在 NT 门处会增加**；且 NT 门是唯一可能让记录突破进入记录的步骤。

### 2.6 哪些量与 J 无关

高度（`A`、`ht`、不动点 15/2、47/2）、秩（`r -> max(r,d)`、`r -> r+1`）、每个 a 步的

只有**步数**受 `R_0 = j_0+Gamma_0 <= J` 约束（见 §6）。

## 3. R3：certify_Q

### 3.1 定义

**定义.** 固定预算 `P`（初始一致精度）。`certify_Q(j, C/Q, b; P)` 成立，当且仅当从类
`delta = C*Q^{-1}+b*2^j mod 2^{j+1}` 的**代表元** `(x,Theta) = (2^j, 2^j + delta_sym)`
出发的精确游走：无 `x=0`、终止于偶交叉、且所有记录 `< P`。
（取 `delta_sym` 为 `delta` 在 `[0,2^{j+1})` 的整数；与 Prop 3.2 的 `(2^j,2^j+delta)`
完全一致，`P = j+1` 时就是已接受的 `certify(j,delta)`。）

**命题 3.1（与 Prop 3.2 的关系）[A].**
(i) `certify_Q(j,C/Q,b; j+1) <=> certify(j, delta)`，其中 `delta = C*Q^{-1}+b*2^j mod 2^{j+1}`。
    故**有理描述不改变可认证性**；`(C,Q,b)` 只是 `delta` 的名字。
(ii) 若 `certify_Q(j,C/Q,b;P)` 且某实际状态与该代表元的初始数据在精度 P 上一致
    （`min(v2 dTheta, v2 dx) >= P`），则它走出同一参数/类型序列、同样终止、记录 `< P`。
    证明即 Lemma HP（`PROOF_EXT.md` §2），需要 HP 的 `x*!=0` 与 `j_0` 相等，
    这里 `x*=2^j`，`j_0=j` 自动相等。
(iii) 只由类（`P=j+1`）得到的是 `certify(j,delta)`；想要预算 `P>j+1` 必须用实际来源
    （affine beta / 具体 `u`），这正是 O2。

**推论 3.2（x=0 与提升位）[A].** Q>1 时 a 步的 `x'!=0`，故 `certify_Q` 的"无零"条件
对 Q>1 自动成立；`b` 只通过 `delta` 进入，不单独限制。`Q=1` 的共振（`x'=0`）是 NT 门，
必须由实际 `u` 或代表元的精确位解除。

### 3.2 well-defined 性

`certify_Q` 作为 `(j, 类, P)` 的函数是 well-defined 的（定义即运行精确游走）。
作为 `(j,C,Q,b)` 的函数它**只通过 `delta` 依赖 C**：这是 (N1) 的直接推论。
需要在有限范围检验的是：不同 lift（`C -> C+2^{j+1}Qt`，换 `(C,b)` 名字）给出同一答案
（在 `certify` 预算下），以及 `b=1` 的 `certify_Q(j,C/1,1)` = `certify(j, C+2^j)`。

### 3.3 与窗口证书 [B] 的关系

已接受窗口证书：`5<=j<2e7`、`delta in [-12,15]` 全认证，只有 `(5,5),(5,-11)` 例外；
另有 `5<=j<=18` **全残基**证书（例外：`j=5` 4 个、`j=8` 4 个、`j=12` 4 个、`j=14` 4 个、
`j=17` 8 个，共 24 个）。故**一个有理着陆类被认证，当且仅当它的残基落在这些证书范围内**，
与 Q 无关。这是本方向最有用的单条结论（把"有理类"问题化归为"残基"问题）。

### 4.2 定理 RAT-1（类决定性 + 记录账）[A] —— 本方向的主定理

> (a) 每个链的转移按 §1.2/§1.3 的三分类/五分类精确成立（含模数与提升位）；
> (b) 秩：A1 反射 `r'=r`；A2/NT 门的 catapult 描述 `r'=r+1`（3-约分后 `<=r+1`）；

>     （一步下降每次只降 1），全部 `R_t<=j_0`，且任何与起点同类（mod `2^{j_0+1}`）的状态
>     走同一参数/类型序列；
> (d) 若每个 a 链都有 `p_t != j_t-1`，则结论 (c) 成立；充分条件是

**证明思路**：(a) §1；(b) §2.1/§2.5；(c) 每步 `j` 至少降 1、强下降/b/c 降 >=2 且

记录从 `j_0` 出发不增；(d) 若 `|3Qk+C| < 2^{j_t-2}` 则 `v2(3Qk+C) <= j_t-3`，
故 `p_t <= j_t-2`，不是 NT 门；`3Qk+C=0` 时 `p=+inf` 反而落入一步下降（Q=1）。

**注意 (c) 是"如果"型**：它不提供 J-无关的充分条件；(d) 才提供，而 (d) 是秩上界（§4.5）。

### 4.3 定理 RAT-2（gateway 的显式化解）[A]

> 若输入类已知到 `2^H` 且 `m<H`，输出类确定；否则（`m>=H`）输出类需要更多位。

### 4.4 着陆证书的判定（类层面）[A]+[B]

> 设着陆步给出类 `delta'`（`=C'Q'^{-1}+b'2^{j'+1}` 的残基），预算 `P`（类层面 `P=j'+1`）。

**重要**：着陆的**实际**记录预算是 `R_land = j'+Gamma`（`Gamma>0`），而类只给 `P=j'+1`，
所以类证书要求 `R<=j'` 是**比需要更强**的条件，因此 [B] 证书可用；但反过来，
用不上 `Gamma` 的松弛是类层面的真实限制（要松弛就必须用实际来源，O2）。

### 4.5 精确来源条件（三个候选，按"是否是参数上界"分组）

* **(DEPTH) 秩—参数关系**：`Q_t(kappa(j_t)+h_t) < 2^{j_t-2}` 对所有 a 链。

  **诚实声明**：这是对秩 `r_t` 的上界（给定 `j_t`）。它不是 CAL-C/R1/H3 型的"参数上界"

  上界型假设，必须按"关系"而不是"全局 cap"陈述。
* **(NC) 纯同余**（若禁止一切上界）：`3Q_t k_t + C_t not≡ 2^{j_t-2} (mod 2^{j_t-1})`，

* **(AFF) gateway 的 affine 判据**：`v2(beta') < J-Gamma-1`（STOP_CHECKPOINT 的形式），
  在我的记号里就是 `m+1 <= sigma_t`（gateway 前的系数精度），等价于"gateway 对不抬高记录"。

### 4.6 N(h) 的判定

* 候选 `N(h) = O(log h)`（由 gateway 高度压缩 23.5 + 3^{-t}(h-23.5) 猜想）：

  `N0=2e7` 只在把 `j<=18` 段交给已接受 [B] 窗口证书时以"证书范围"的身份出现（见 §4.7）。

### 4.7 复合推论（候选，最有用的可写形式）[A]+[B]

### 5.1 O1 放进表示（`ORBIT_SHIFT_OBSTRUCTION`）

规范源 `P=49`：`x0=5*2^49`（`j=49,u=5`），`Theta0=x0+1`（`D0=1`，`Q=1,C=1,b=0`，ht=1）。
位移 `eta_r = -5+8/3^r`：`D = -4+8/3^r`，即

    Q = 3^r,  C = -4*3^r + 8,  b = 0,  ht = |-4+8/3^r| <= 4,  rank r.

`gcd(C,3)=1`（`C ≡ 2 mod 3`）✓。首个 a 步 `k=20`（`tau(48)=40`）：

    3Qk+C = 56*3^r + 8 = 8(7*3^r+1)   =>   p_0 = 4+v2(7*3^r+1),
    x' = 15*2^48 + 112 + 16*3^{-r},   3Qx'/... 精确地  3^r x' = 16(A*3^r+1),
    A = 263882790666247 = 15*2^44 + 7.

故 `v2(x') = 4+v2(A*3^r+1)`。**关键发现**：O1 的危险 `r` 满足 `v2(A*3^r+1) >= sigma-5`，
从而 `v2(7*3^r+1) = 44` 恰好（因 `A ≡ 7 mod 2^44`，若 `v2(7*3^r+1)>=45` 则
`v2(A*3^r+1)=44 < sigma-5`，矛盾），于是

    p_0 = 4 + 44 = 48 = j - 1.        （O1 恰好是引理 A 的 (A3) NT 门）

即：**O1 不是"高度不够"，而是秩—参数关系被破坏后的 NT 门**。定量：

* `(DEPTH)` 在源处要求 `3^r*(kappa(49)+4) < 2^47`；`kappa(49)=125064`，
  `2^47/125068 = 1.1253e9`，`3^18=3.87e8` ✓、`3^19=1.16e9` ✗，故 **`r<=18` 时成立**，
  `r>=19` 时违反。O1 的危险 `r >= 6.6e14`，违反幅度约 `1.04e15` 位。
* 锐化 O1 §4 的必要条件：由 `v2(A*3^r+1) <= log2(A*3^r+1)` 得
  **`r >= ceil(log_3((2^{sigma-5}-1)/A))`**，用 50 位十进制对数算得
  `r_min = 663,542,339,794,048`（比 O1 的 `5(sigma-53)/8 = 657,306,078,883,963.125`
  强 0.95%；精确位长判定留给 `rat_o1.py`，[P]）。
* O1 违反的是定理 RAT-1(c) 的"无 NT 门"，不是 (b) 或 §1 的代数。

### 5.2 O2 放进表示（`STOP_CHECKPOINT`）

族 `u=(2^{m-4}-1)/3`（m 偶 >=6）、`x=32u`、`Theta=x+5`：即 `j=5,u` 奇、`D=5`、
`Q=1,C=5,b=0`、ht=5。j=5 的 a 步（k=1）：`x' = 48u+16 = 16(3u+1) = 2^m`，故 `m=v2(x')`；
`3D' = 10-x'`，得 `D' ≡ (10-2^m)/3 (mod 2^{m+1})`（即 `(C',Q',b')=(10,3,1)`）。
记录 `5 -> m+1`。本轮内联核对 `m=6,8,...,18`：`x'=2^m`、`v2(x')=m`、
`3D' ≡ 10-2^m (mod 2^{m+1})` 全部成立。

**结论 [A]**：任何只依赖 h 的**记录界**对**任意来源**不存在；`ht<=5` 的状态可以有 `m+1` 的记录。
`m` 是 gateway 的 affine 小部 `beta'`：`beta' = 6d+8-beta/2`（STOP_CHECKPOINT 的形式），
故 `(AFF)` 判据 `v2(beta')<J-Gamma-1` 正是"gateway 不抬高记录"的精确条件。
我的记号里它等价于 `m+1 <= sigma_t`（gateway 前精度）。

**但必须加限定（对齐 accepted `work_claude_shift` Lemma CB）**：对**规范裸 tie 入口**
（前驱链 `y>=N0`、入口 automaton 值 `d_5 in {5,-11}`、随后 `X(4)` 的 catapult），该节证明
`0 < Z <= 9(y-1)P(y-1)+3|d_y|+24 < 2^{sigma-1}`，故 `m` 被认证且 **`m < G(y)+1`**。
所以 canonical gateway 的记录跳幅是 `O(log y)`，不是任意的；O2 的任意 `m` 属于构造局部状态
（STOP_CHECKPOINT 明确 "NOT claimed to occur in S(J)"）。因此：
* "no h-only record bound" 对**任意来源**成立（[A]，O2 族）；
* 对**规范裸 tie gateway**，`m <= G(y)+1`（[A]，Lemma CB 导入），于是记录跳幅 `<= G(y)-4`；
* 介于两者之间的其它 gateway 来源（H5_res 的 (i)–(v) 类）仍无统一界，必须逐个用 (AFF)/Lemma CB 型论证。

### 5.3 O3 放进表示（`OPTIMAL_PHASE_ENCODING`）

O3 的代价 `2r + ceil(max(0,1-c,c-2))` 在本记号下就是 `2r + ceil(h_pen)`，而
`h_pen = max(0,A-1/2)`（§2.1）。因此：**秩 r 与高度 A 是描述的两个收费项，a 步不改变它们
（A 精确保持、r 不变），所以"按高度/秩枚举类"的覆盖数 = 每层至多 `2h+1` 个类 × (秩层数)**。
O3 的精确计数（S=m=64 时）`8,338,590,849,833,250 < 2^64` 正是这个意思。
后果 [A]：参数 `j` 处有 `2^{j+1}` 个类，而"低代价描述"只有多项式多个，故**不可能**
用扩大 `(h,r)` 有限扫描覆盖全部类（正是任务 O3 的要求）；必须用实际来源/相位限制。
这也解释了为什么 `certify` 是类层面的事实（§3）而不能由有理描述"批量生成"。

## 8. 规范 vs 合成的取法

* **规范实例**：`Calendar(B)`（`B in {64,256,512,1024}`）。
  - `cal.crossing(n)` 给 `kind/time/epsilon/odd/omega/head_ratio/tail_ratio/head_lambda/tail_lambda`；
  - b/c 步用 `c'_W = (head_ratio+2*tail_ratio)*2^n`、`lambda'_W = head_lambda+2*tail_lambda+3`

  - `cal.projected_epoch(J)` 用于取 `S(J)` 的投影链（终止/上限/工作限额）；
  - `Calendar(B)` 的可查询范围是 `n < boundary_pointer`（`B=512` 时约 `1e800`），
    但**所有交叉的 `eps` 只由参数 `<=B` 的核决定**：实测 `n in [4,4000)` 与
    `[1e9,1e9+4000)` 的奇交叉分布相同（`a/eps=0`、`b/eps=1`、`c/eps=3`），
    而 λ-walk 表到 `1e6` 有 28 个 `eps=5` 的 c 型奇交叉

    作为 `tau/eps/lY` 的独立交叉核对。
* **合成实例**：显式标 `canonical:false`；必须用精确整数，不许浮点判定模数。

## 13. 实现阶段（`verify_rational.py`）发现并修正的陈述

本轮按本计划实现了 `verify_rational.py`（1,328,418 次精确检查，16.9 s）。以下是实现逼出来的
修正；**陈述已按此更新**（§2.4、§4.2(b)、§4.7），失败原样记录在 `checks.json`。

1. **秩递推不是等式**（修正 §2.4 / `(RB2)` / RAT-1(b)）。
   原计划写 `r' = max(r,d)`（b/c）与 `R' = ...`；脚本在 4,032 个合成 b/c 与 9,120 个规范 b/c 上
   找到反例：`Q=9, C=55, s=2/9` 给 `57/9 -> 19/3`（秩 2->1）；`Q=9, C=1, s=-1` 给
   `C2_raw = 0`（秩 2->0）。正确形式：`r' <= max(r,d)`，等号当且仅当 `3 ∤ C2_raw` 或 `max(r,d)=0`；
   约分可一次降多级。gateway 的 `r'=r+1`（r>=1）不受影响（此时 `3 ∤ C'` 必成立）。
   **这条修正不改变任何记录/高度结论**，只把"秩增长的精确条件"写对。
2. **gateway 检验的精度语义**（测试侧修正，不是定理修正）。原计划把状态写成
   `D = class(mod 2^{j+1}) + lift·2^{j+1}` 却按 `H` 位声明精度；`m<H` 的公式在 `m = H = 6`
   时失败（710/33,220），因为 `D` 的实际精度只有 `j+1=6`。改为
   `D = (C·Q^{-1}+b2^j mod 2^H) + lift·2^H` 后 0 失败。这反过来**正面确认了** `m<H` 条件的必要性：
   在 `m >= H` 的 184 个实例上，同一类 mod `2^H` 的不同 lift 给出不同的 `m`。
3. **j=5 的 NT 门就是 gateway，不是失败**（测试分类修正）。RAT-C 的 walk 在 j=5 命中
   `p0 = 4`（例如 `(10-2^m)/3` 的 14 个 m、`(26-2^m)/3` 的 13 个 m）时，属于 §4.3 的 gateway，
   需要 Lemma CB / 实际精确位来化解，不能计作 NT 门失败。脚本已把两者分开统计。
4. **(DEPTH) 在采样轨迹上只于 j=5 失败**（新增 [B] 数据）。2,946 条 walk 中 `j>=19` 上 0 次
   (DEPTH) 失败、0 次 NT 门、0 次记录上升；步数 `<=2`。所以 RAT-C 的假设对这三个族在
   `m<=1000` 上确实成立，但**是被逐步检查确认的，不是由初值高度推出**。
5. **小 j 全残基扫描与已接受陈述逐项吻合**（[B]）：j=5,8,12,14,17 的例外数为 4,4,4,4,8；
   j=5 的对称残基为 `{5,21,-27,-11}`、j=8 为 `{58,186,-198,-70}`、j=12 为
   `{1012,3060,-3084,-1036}`，与 `work_claude_shifted` §4 列出的一致。
